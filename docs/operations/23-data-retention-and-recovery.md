# 儿童数据保留、导出与恢复边界

## 数据最小化

服务端只收集家庭成员、成长任务、奖励账本、纯模拟财商订单和本 App 的分钟级 UsageEvent。不得采集其他 App、通信内容、精确位置、广告标识、真实银行/证券数据或用儿童数据做操纵性留存分析。

## V1 保留基线

| 数据 | 建议在线保留 | 原因 |
| --- | --- | --- |
| UsageEvent 明细 | 默认 90 天，可由家长设为 30–365 天 | 家庭报告核对与数据最小化平衡；由每日调度自动清理 |
| 不可变 Ledger/订单/审核 | 家庭账户存续期 | 保障余额、费用和奖励可对账 |
| AuthSession | 到期后 30 天内清理 | 安全审计且不长期保存可用 Token；数据库仅存哈希 |
| 加密备份 | 7 日/4 周/12 月轮换 | 家庭灾难恢复；到期安全销毁 |

Stage 26 已提供家长 JSON 导出、删除预览、一次性十分钟确认 token + 服务端 PIN 的受约束删除，以及每日自动保留任务。家长可在 Android 隐私中心配置 30–365 天并立即执行一次；每次策略变化和运行记录原因/触发方/删除或脱敏数量。自动任务只删除到期 `UsageEvent`、脱敏已过期临时放行原因并清除过期确认 token，不删除 Ledger、订单、费用、幂等、防重复完成事实或必要审计。主库能力已在 PostgreSQL 16.15 验证；不可直接承诺已复制到外部备份中的数据即时物理擦除，备份仍按下述轮换与恢复边界处理。

## 恢复原则

- 恢复只在新建隔离数据库演练，验证 Flyway 版本、核心表数量和抽样业务计数。
- 生产切换需要维护窗口、最新备份 SHA-256、应用停写和家长确认；自动化脚本不覆盖现有数据库。
- APK 更新失败不得清除 App 私有数据；系统级覆盖升级和数据保留仍需真实平板证据。
