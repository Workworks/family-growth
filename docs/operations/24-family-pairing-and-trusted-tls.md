# 家庭成员配对与可信 TLS

Stage 29 的邀请和设备配对是短期引导，不是 TLS 或长期认证的替代品。正式 Android 包只连接系统信任的 HTTPS；证书名称、有效期或信任链失败时必须先修复服务端，不能在 App 内忽略错误。

## 推荐部署

1. 为家庭服务配置固定 DNS 名称与系统信任的证书，并只暴露必要的 HTTPS 端口。
2. 先在已登录家长端生成 PARENT 或指定孩子的 CHILD 配对码。设备码五分钟有效、单次消费，只存 SHA-256；不要写入日志、二维码历史或工单。
3. 新设备输入服务地址、配对码和可辨识但不含孩子全名的设备名称。成功后服务端登记 `device_id`，所有由该配对签发的会话均绑定设备。
4. 家长在“家庭协作”查看设备。遗失、转让或异常设备应立即撤销；服务端同事务撤销其有效会话，下一请求返回 401。
5. 第二位家长使用十分钟邀请设置自己的六位服务端 PIN。OWNER 可重置另一家长 PIN 或撤销 GUARDIAN；重置和撤销都会使旧会话失效。

## 轮换与故障处理

- 代码过期、已使用或输入错误均统一返回认证失败；重新生成新代码，不延长旧代码。
- 配对后无法连接时，先核对设备系统时间、DNS 和完整证书链，再检查反向代理是否保留 `/api/v1` 路径。
- 撤销未即时生效属于安全故障：停止对外服务，确认 `auth_session.device_id` 已绑定且 `revoked_at` 已写入，再恢复访问。
- 不通过聊天、Git、Release 附件或证据文件保存 PIN、Token、邀请码、配对码、私钥或证书私钥。

机器接口见 [OpenAPI](../openapi.yaml)，一般部署与恢复见[部署指南](10-deployment-guide.md)和[密码与密钥](19-password-and-secrets.md)。
