# 家庭经济实验室运维说明

Stage 31 的“储蓄奖励、模拟市场、持有期费用、固定价装扮”只服务家庭教育账本，不接银行、支付、证券、基金代码、真实行情或投资建议。

## 家长操作顺序

1. 先在家长端设置周期储蓄奖励率与最低余额。奖励率上限为 10%，规则每次修改都会生成新版本。
2. 每个孩子、每个周期由家长显式结算一次。服务端用同一事务写奖励事实、`SAVING_REWARD_CREDIT` 和 `SAVING_REWARD_DEPOSIT` 两条同组 Money 流水，再增加 Saving；重复幂等键只返回原事实。
3. 模拟基金先有 NAV，再设置家庭固定种子和最大日波动。每日 tick 只由种子、基金 ID 和日期确定；同基金同日期永远返回同一结果。
4. 卖出前必须查看持有天数、基础卖出费、提前赎回费、总费与预计到账。确认时服务端校验原预览快照，规则或 NAV 变化后旧预览不得成交。
5. 装扮只有固定 Coin 价格，仍走孩子申请、家长批准、现实履约流程；禁止随机箱、抽奖、限时折扣和倒计时。

## 审计与排障

- 规则和操作事实位于 `saving_reward_*`、`simulated_market_*`、`fund_holding_fee_rule`、`economy_lab_action`；账本变化仍以 `ledger_entry` 为唯一余额审计路径。
- 结算返回 `409` 时，先检查最低储蓄余额、同周期是否已结算、幂等键是否被不同载荷复用。不得通过直接改余额或删除流水规避冲突。
- tick 返回 `409` 时，检查是否缺少有效市场规则或基金 NAV。同一天已有 tick 时应读取原结果，不手工覆盖。
- 幼儿园孩子端只显示“小星星、存起来、请家长一起”等简单结果，不显示 Money、利率、NAV、涨跌、交易或费用入口。

## 备份与恢复

V28 表与 Wallet/Ledger 必须在同一个数据库备份点恢复。不得只恢复余额而遗漏奖励、订单或流水；恢复后运行 Flyway 校验和 Stage 31 API 回归测试。
