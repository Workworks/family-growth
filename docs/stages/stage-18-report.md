## 目标与非目标

用户可观察目标：家长/孩子视角按钮在手机和平板上清楚、稳定；孩子能浏览家长添加的奖励、打开详情并表达“我想要”；孩子可在 App 内主动播放原创教学短视频，累计看完 90% 后对应任务进入待家长确认状态。

范围内：Compose 角色切换布局、奖励详情/兴趣持久化、原创本地视频资源、真实播放时长累计、任务提交、旧数据兼容、Android 自动化与 v0.3.2 Release。范围外：第三方视频平台、直播、推荐算法、自动播放、儿童直接兑换、课程 CMS、服务端视频进度同步和真实设备替代验收。

## 边界与不变量

- 儿童一级导航最多三个；新增能力嵌入既有“今天/任务/我的”路径。
- 家长视角继续受 PIN 保护；UI 切换不能替代服务端 RBAC。
- 奖励“我想要”仅是可撤销兴趣，不扣 Coin、不建已支付订单、不产生 Ledger。
- 视频无广告、推荐、追踪、自动播放和连播；只累计实际播放秒数，达到 90% 才提交且同一视频幂等。
- 视频任务固定 Money 0、Coin 2、XP 5，家长批准后才入账；孩子端不展示复杂账本术语。
- JSON 新字段提供默认值，v0.3.1 本地数据升级后必须可读取。
