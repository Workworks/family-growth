## 目标与非目标

目标：在现有 Android APK 中交付可操作、可在设备本地持久化的 Family Growth 基础体验版，粗粒度覆盖 Stage 2–11 的用户可见能力：孩子/家长模式、成长任务、提交/审核/奖励、钱包流水、压岁钱、兑换、奖励商店、储蓄、愿望、纯模拟基金、防沉迷计时、今日报告和 GitHub Release 更新入口；前端达到可连续使用的完整信息架构与视觉质量。

非目标：不在本 Stage 完成生产级服务端认证/同步、复杂工作流、深度可配置规则、真实金融、系统级跨 App 防沉迷、复杂报表、图片凭证、通知、离线冲突合并或正式商店发行。Stage 3–10 的完整后端/数据库/E2E 状态不因本地基础体验而自动变为 `COMPLETED`。

## 边界与不变量

- 基础体验数据保存在 Android App 私有本地存储，禁止自动插入展示型业务数据；空状态引导用户自行创建。
- 家长入口使用本地 BCrypt PIN 基线；服务端认证和跨设备授权仍属后续深化，UI 必须明确“本机基础版”。
- Money/Coin 的本地变化必须同时追加本地 LedgerEntry；奖励、压岁钱、兑换、商店、基金买卖均不得直接改余额。
- 模拟基金只使用明确标注的虚拟 NAV，由家长调整教学涨跌；不接真实代码、行情或推荐。
- 防沉迷只统计本 App 孩子模式使用时长；达到本地每日限制后阻断孩子工作区，不宣称控制其他 App。
- GitHub Release 安全链保持 Stage 11 契约，不降低 HTTPS、digest、FileProvider 或系统确认要求。
