# Stage 31：家庭经济实验室

状态：`BLOCKED`（Agent 可执行工程已完成；仅缺目标平板运行态验收）

产品 Phase：V1 虚拟经济深化 / P2

需求：REQ-001、REQ-013、REQ-021、REQ-051、REQ-052；Backlog P-06、P-08、P-09、P-10、P-11

## 用户可观察目标

家长在同一“家庭经济实验室”查看并配置储蓄奖励、可复现模拟市场、买卖/提前赎回成本和固定价格装扮。孩子只看到适龄结果与清楚费用；幼儿园不显示利率、波动、NAV 或交易按钮。

## 范围与边界

- 家长配置版本化周期储蓄奖励率并显式结算；同一孩子/周期只能结算一次，奖励进入 Saving，同时用同组 Money Ledger 展示先奖励后存入的完整路径。
- 模拟市场只用家庭自定种子、最大日波动和本地日期生成确定性 NAV；同基金/日期重复执行返回同一事实，不接真实代码、行情或投资推荐。
- 卖出预览必须把基础卖出费、持有天数、提前赎回费率/金额、总费和预计到账一次展示；确认严格使用预览快照。
- 固定价格主题/装扮复用 RewardProduct 审核与履约账本，不提供随机箱、抽奖、限时折扣、稀缺倒计时或真实购买。
- Android 家长端统一现有预算、兑换、储蓄、模拟基金、零钱回收和装扮入口；儿童端不新增一级导航。

## 实现结果

- V28 新增 6 张规则、事实与审计表，并为卖出预览/订单固化持有天数、提前费率和金额；`reward_product.product_kind` 区分现实奖励与固定价装扮。
- 储蓄奖励使用家长版本化规则与显式周期结算。奖励先进入 Money、再转入 Saving，两条不可变流水共享业务组，钱包净变化为零，Saving 增加；同一孩子/周期不可重复。
- 模拟市场用 SHA-256 派生的家庭固定种子、基金和日期生成受限基点变化；同基金/日期只存在一个 tick，不连接真实行情。
- Android 家长端把规则与动作放入现有管理页；幼儿园孩子钱包完全隐藏 Money、兑换、提现、NAV、涨跌和交易，只保留小星星与“请家长一起”。
