## 目标与非目标

目标：建立仓库、Agent 治理、文档结构、产品/系统/数据库/账本/模拟投资/Android UI 设计、实施计划与验收契约，使 Stage 2 可以在明确边界内启动。

用户补充的初始定位已纳入：学习类 App、Android 平板、防沉迷、今日使用统计、奖励与可体现 Money 的虚拟钱包、压岁钱默认 1:1、模拟基金和带透明手续费的零钱回收。

非目标：不生成 Spring Boot/Android 业务代码，不建数据库，不宣称 APK、账本或基金功能可用，不执行真实金融交易。
