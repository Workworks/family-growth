# Stage 27：成长计划、里程碑与家庭成长档案

状态：`BLOCKED`（可离线工程已完成；仅缺目标平板 V27-08）

产品 Phase：V1 成长深化 / P1

需求：REQ-001、REQ-050、REQ-051；Backlog P-01、P-02、P-03、P-12

## 用户可观察目标

家长可以为孩子建立有类别、学段、目标和明确状态的成长计划，把现实中的阅读、运动、语言、生活自理和亲子互动记录为带日期的里程碑；可选图片只进入受控家庭档案。0–2 岁只提供家长记录模式，不出现儿童屏幕任务。家长报告按计划、类别、里程碑和复做事实呈现，不生成分数、排名或人格结论。

## 范围内

- `GrowthPlan` 增加 category、ageStage、target 与 `DRAFT/ACTIVE/PAUSED/COMPLETED/CANCELED` 状态；状态转换由服务端校验、幂等并留不可变动作。
- `GrowthGoal` 增加目标描述和 `ACTIVE/COMPLETED/CANCELED` 状态；归属和更新受 family/child/plan 权限保护。
- `GrowthMilestone` 保存发生日期、类别、标题、具体观察、来源计划/目标和创建者；历史记录可更正但保留动作，不原地静默改写。
- 可选 `GrowthArtifact` 只接受 JPEG/PNG/WebP、最多 5 MiB；服务端校验文件签名、MIME、大小和 SHA-256，二进制保存在家庭数据库并仅允许家长读取。
- 0–2 岁家长记录模板覆盖亲子阅读、运动、语言互动、生活自理和情绪连接；不创建孩子登录入口、屏幕课程或奖励。
- 成长报告只汇总计划状态、类别、里程碑、任务完成/复做和明确使用事实；不推断能力、诊断、智力或同龄位置。
- Android 家长端提供成长年轮、计划编辑、里程碑记录、可选图片和事实报告；孩子端现有简化成长页不增加复杂财务或档案入口。

## 范围外

- 人脸识别、云相册同步、公开分享、社交动态、医学/心理诊断、同龄比较和 AI 生成儿童评价。
- 0–2 岁儿童自主操作、为了记录而增加屏幕时长、用图片或里程碑触发随机奖励。
- 真实设备相册权限、相机兼容、TalkBack/旋转和图片解码运行态验收；缺设备时保持独立 `BLOCKED`。

## 安全与数据不变量

1. 所有写入和图片读取仅家长角色；跨家庭对象按 404 隐藏，孩子访问 403。
2. 图片不写日志、审计 detail、导出 JSON 或错误响应；只导出元数据和 SHA-256。删除孩子数据时删除图片二进制并保留最小动作事实。
3. 文件名不作为路径，服务端不写用户可控文件系统路径；以数据库二进制和生成 UUID 保存。魔数与 MIME 不一致、SVG/GIF/视频、空文件和超过 5 MiB 全部拒绝。
4. 计划/目标/里程碑变更使用 version 与幂等键；完成或取消后的计划不能恢复为草稿，历史任务、奖励和账本不受影响。
5. 里程碑和报告不写 Wallet/Ledger；如未来奖励须进入独立 RewardRule Stage，不得借记录行为直接发钱。

## 前端两遍设计

### 第一遍：成长年轮

- 主题：家庭成长档案；用户是家长；页面唯一工作是“记录一件现实中已经发生的成长事实”。
- 色板：`松针 #2F6B59`、`新叶 #77A96B`、`晨光 #F2C66D`、`纸页 #F7F3E8`、`墨灰 #273238`、`雨蓝 #5E7D8C`。
- 字体角色：现有 Material 中文无衬线的 `headlineMedium/titleLarge` 作为档案标题，`bodyLarge/bodyMedium` 作为记录正文，`labelMedium` 只用于日期和状态；不引入不可控远端字体。
- 布局：宽屏左侧计划书脊，右侧成长年轮时间轨迹；手机按“当前计划 → 记录按钮 → 时间轨迹”单列。签名元素是一条随日期延展的树枝轨迹，叶片节点只编码里程碑类别，不编码分数。

```text
┌ 计划书脊 ─────┬──────── 家庭成长年轮 ────────┐
│ 当前计划      │  今天记录一件真实发生的事      │
│ 草稿/进行中   │    ● 阅读 —— 一起讲完故事      │
│ 暂停/完成     │    │                           │
│               │    ● 运动 —— 自己跨过软垫      │
└───────────────┴───────────────────────────────┘
```

### 第二遍批评与收敛

删除通用进度环、连续天数、彩色徽章、成长分数和自动庆祝；这些元素会把记录变成表现压力，也不代表真实成长。保留一条低刺激时间轨迹、明确状态和“记录现实行动”主按钮；Reduced Motion 下无节点动画，图片只显示静态缩略图与可读替代说明。
