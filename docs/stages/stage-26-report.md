# Stage 26：连续性、隐私、防沉迷与发布总验收

状态：`IN_PROGRESS`

产品 Phase：全面教学收口 / P0

需求：REQ-030、REQ-031、REQ-050；Backlog T-13、T-16、T-18–T-22、T-29、T-30；LIM-013

## 用户可观察目标

把 Stage 20–25 的四学段教学能力收成一个可长期家庭使用的安全版本：家长改变年龄或学段时，孩子立刻进入对应页面和课程，旧课程与历史证据不丢失；家长可以导出孩子数据并执行受约束删除；防沉迷除每日/单次时长外支持睡眠时段、临时放行与审计；Android 对生产服务、断网、冲突和覆盖升级有清楚状态，最后形成稳定签名 APK 和 GitHub Release。

## 范围内

- 学段迁移预览与执行：保留所有历史 Assignment/Attempt/Completion/Ledger，只归档不再适龄的未开始自主课程；推荐学段变化不静默覆盖家长 override。
- 家长专属儿童数据导出：机器可读 JSON，包含资料、学习事实、目标/复盘、使用事实与账本；不包含 PIN、Token、答案键、家长私密说明或服务 secret。
- 受约束删除：默认去标识化儿童资料和可删除内容，保留账本、审计、幂等与安全事件的最小完整性事实；先提供预览、二次确认、幂等和审计。
- 完整 App 内防沉迷：每日/单次上限、睡眠时段、家长临时放行、原因/到期/使用审计；孩子不能自行修改或延长。
- Android 生产收口：四学段切换后的课程同步、数据权利入口、防沉迷状态、断网/401/409 可恢复状态和可访问文本。
- PostgreSQL、H2、Android 双变体、OpenAPI、文档、签名、更新清单、GitHub Release 与目标平板总验收。

## 范围外

- 真实银行/支付/证券/基金、学校 SIS/班级端、医疗或心理诊断、升学预测、同龄排名。
- 无法撤销的物理备份擦除承诺；服务端只能对受控主库和声明的备份保留周期负责。
- 绕过 Android 系统安装确认、签名/摘要/包名校验或为方便更新降低 fail-closed 门禁。
- 没有设备、部署宿主或网络条件时伪造真机、生产 TLS、备份删除或覆盖升级通过。

## 关键决策

1. 学段变化采用“先预览、再切换、历史只读保留”。不删除旧学习记录，不把旧阶段的 Mastery 或奖励改写为新阶段事实。
2. 未开始且不再适龄的自主 Assignment 标记为归档投影，不影响家长手动布置课程；已开始/待回应/返工项继续可完成。
3. 数据导出由家长 RBAC 发起，服务端流式生成并记录审计；输出使用稳定 schemaVersion，不把 secret 或答案材料放入文件。
4. 删除采用两阶段命令：preview 返回明确保留/删除清单和短期确认 token；confirm 需要家长重新认证、幂等键和 token。账本与审计仅去标识化，不破坏金额守恒和追责链。
5. 默认睡眠时段 `21:30–06:30`，按家庭时区计算；临时放行默认 15 分钟、最多 60 分钟、必须填写具体原因并自动到期。3–5 岁仍由家长共同使用且遵循更短的既有上限。
6. 防沉迷的任何“允许/拒绝/放行/到期”都是事实记录，不做羞辱、惩罚、连续签到或损失厌恶；锁定页提供离屏建议和家长入口。
7. 发布只能在离线门禁、PostgreSQL、签名身份、APK SHA-256/大小/包名/版本、更新清单与远端 Release 复验全部通过后执行；真机项独立报告。

## 数据保留边界

| 数据 | 删除确认后 | 原因 |
| --- | --- | --- |
| 姓名、生日、个性化配置、自由文本目标/复盘 | 删除或替换为不可逆匿名占位 | 儿童隐私最小化 |
| 未开始课程、兴趣、愿望、非财务使用明细 | 删除 | 无持续完整性需要 |
| Assignment/Attempt/Completion 汇总事实 | 去标识化保留最小状态/时间 | 防重复结算与历史一致性 |
| Wallet/Ledger/兑换/兑现/模拟基金流水 | 去标识化保留 | 账本守恒、费用透明与家庭对账 |
| RBAC、审计、幂等、安全事件 | 去标识化保留最小字段 | 权限、重放与安全追责 |
| PIN、Token、secret、答案键、家长私密说明 | 从不导出；按既有生命周期删除 | 安全红线 |
