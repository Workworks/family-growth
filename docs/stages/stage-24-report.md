# Stage 24：初中学科实验台

状态：`IN_PROGRESS`

产品 Phase：全面教学初中深度

需求：REQ-030、REQ-031、REQ-034、REQ-035、REQ-047、REQ-048、REQ-050；Backlog T-27

## 用户可观察目标

让 12–14 岁孩子在不被排名、催促或能力标签驱动的前提下，按学科看见章节与知识点，自己调整短期学习顺序，围绕“提出问题 → 找证据 → 解释 → 安排再练”完成一段可暂停的学习。家长看到的是计划、实际行动、明确求助和再练事实，而不是推测分数。

本 Stage 完成后，家长能从原创初中模板建立、发布和安排课程；孩子进入独立的“学科实验台”，选择下一项、调整未开始项目顺序、完成证据活动并复盘；错因和再练沿用不可变事实链，课程认真完成后仍按家长预设固定奖励并由家长确认结算。

## 范围内

- 初中课程的学科、章节、知识点、学习目标、实验/实践安全说明和建议时长元数据；发布后不可修改，历史 Assignment 永久引用原版本。
- 孩子可调整自己尚未开始的初中自主 Assignment 顺序；进行中、待家长回应、已完成和返工项目不能被排序操作伪装成另一状态。
- 初中专属 Android 页面、原创模板、学习支持/间隔再练、阶段复盘和家长事实视图。
- 服务端鉴权、对象权限、幂等、乐观/并发保护；H2、PostgreSQL、Android 双变体和治理门禁。

## 范围外

- 班级、教师端、考试排名、同龄比较、自动诊断能力、升学预测、AI 代写答案或以正确率自动调整奖励。
- 真实实验室高风险操作、化学药品配制、明火/高压/锐器指导；家庭实验只使用审核过的低风险材料并要求适当成人协助。
- 抽取第三方视频流、绕过平台页面、自动播放下一节或把网页停留时间冒充掌握证据。
- Stage 25 高中选科/项目探究和 Stage 26 数据权利/完整防沉迷/发布总验收。

## 体验设计（两遍）

页面的具体主题是“12–14 岁学生安排下一段学科学习”，单一工作是从真实计划中选定下一项并完成证据闭环。

第一遍采用“实验记录夹”方向：夜航蓝 `#17324D`、测量青 `#4E8799`、证据黄 `#E2B44A`、纸页灰 `#F5F7F4`、石墨 `#27343D`、纠偏橙 `#C66A3D`。标题使用系统 Sans 的紧凑粗体，正文使用清晰常规字重，章节/状态使用等宽数字与短标签。布局以左侧学科轨道、中央当前实验页、右侧证据/再练窄栏构成；窄屏折叠为纵向。签名元素是“证据轨道”：每个节点必须对应真实状态，不是装饰进度条。

第二遍删除拟物试管、霓虹暗色、徽章、连续动画和通用统计仪表盘；保留一处证据黄作为当前节点，其他区域安静。顺序调整使用可访问的“上移/下移”而非只依赖拖拽；Reduced Motion 下不使用位移动画。与幼儿园故事舞台、小学探索夹页结构明确不同。

```text
┌ 学科轨道 ─┬ 当前实验页 ─────────────────┬ 证据与再练 ┐
│ 数学       │ 章节：一次函数              │ 问题  ✓     │
│ 物理  ●    │ 问题：怎样描述速度变化？    │ 证据  →     │
│ 语文       │ [继续找证据]                │ 解释  ·     │
│ 英语       │ 下一项 [上移] [下移]        │ 再练  2天后 │
└────────────┴─────────────────────────────┴─────────────┘
```

## 安全与事实不变量

1. 儿童仍只有“今天 / 学习 / 我的”三个一级入口；初中页提高自主性，不增加无限流、排名、连签、倒计时、随机奖励或羞辱反馈。
2. 排序只影响当前孩子、当前初中学段、未开始的自主 Assignment；服务端按家庭/孩子隔离并留下不可变排序审计。学段切换不删历史。
3. 完成仍只认 Stage 21 活动证据与家长审核；求助、浏览、排序、错误或写复盘均不能自行结算奖励。
4. 错因沿用具体过程类别；家长私密说明、答案键和高风险实验细节不进入儿童投影。
5. 奖励固定、透明、由家长配置并在 Assignment 创建时快照；Money/Coin 变化继续与 LedgerEntry 同事务且只结算一次。
6. 默认当前学习块不超过 25 分钟，到点给中性休息出口；完整时段强制与放行审计归 Stage 26，不在本 Stage 冒充完成。
