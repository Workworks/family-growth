# Stage 29：家庭成员、设备配对与最小待办

状态：`BLOCKED`

产品 Phase：V1 家庭协作 / P1

需求：REQ-001、REQ-013、REQ-021、REQ-051；Backlog P-14、P-15、P-16

## 用户可观察目标

家庭创建者成为 OWNER，可生成十分钟有效、只展示一次的第二家长邀请；受邀家长用邀请码设置自己的 PIN 后加入家庭。OWNER 能查看成员与设备、为忘记 PIN 的另一位家长重置 PIN、撤销成员或设备会话，但不能撤销自己或留下没有 OWNER 的家庭。家长能在同一 APK 切换有权访问的孩子；新设备用五分钟一次性配对码换取明确角色的会话，不再输入 family/parent/child UUID。家庭待办箱聚合任务审核、兑换审批、奖励审核/兑现和课程发布提醒；孩子只看自己的中性回应，不接收催促型系统通知。

## 范围内

- 既有首位家长迁移为 `OWNER/ACTIVE`；新增 `GUARDIAN`，不增加可绕过现有 PARENT RBAC 的角色。
- OWNER 创建/撤销家长邀请；邀请码使用高熵随机值、只存 SHA-256、十分钟过期、一次消费、接受时为新家长设置独立 BCrypt PIN 并签发会话。
- 成员列表、OWNER 为另一家长重置 PIN、撤销 GUARDIAN；撤销原子禁用成员、凭据和全部有效会话，历史审计/账本 actor_id 不删除。
- 家长创建 PARENT_SELF 或指定 CHILD 的五分钟设备配对码；只存摘要，接受后登记设备并签发绑定 `device_id` 的会话。设备撤销只撤销该设备会话。
- 配对 API 返回角色、家庭、成员/孩子最小投影和 OS 信任 TLS 要求；不允许跳过证书校验、不在二维码/日志放长期 token。
- 服务端持久化最小通知/待办：任务待审核、兑换待审核、奖励待审核、奖励待兑现、课程已发布；`source_type + source_id + recipient` 去重，可读、标记已读。
- Android 家长连接页支持服务地址 + 一次性配对码；连接后从服务端成员/孩子列表切换孩子。家长端待办箱可处理既有动作；孩子端只显示与本人有关的中性状态，不请求通知权限。

## 范围外

- 邮件/短信找回、社交账号、云账号、公开发现局域网服务、推送厂商、FCM、后台保活、儿童营销提醒和跨家庭共享。
- 家长细粒度业务权限；V1 的 GUARDIAN 与 OWNER 都是 PARENT 业务角色，只有成员/设备治理限定 OWNER。
- 绕过 HTTPS 证书、自动接受自签名证书、把短配对码作为长期认证或把 PIN/Token 写入本地明文日志。

## 安全与儿童行为不变量

1. 邀请/配对码只展示一次、仅存摘要、短时过期、一次消费；猜测失败使用统一错误且不得泄露家庭/角色。
2. 接受邀请、接受配对、撤销成员/设备和重置 PIN 都在单事务完成，并追加不可变动作审计；被撤销会话下一请求立即 401。
3. OWNER 不能撤销自己、不能降级最后一个 OWNER；跨家庭成员/设备/通知统一 404。
4. 设备配对只在可信 HTTPS 上使用；Android 保持系统证书校验，不提供“忽略证书错误”。
5. 通知不是账本事实，不改变 Wallet/Ledger/Completion；处理动作继续调用原业务事务。删除通知不能删除源业务记录。
6. 儿童无通知红点、倒计时、声音、震动或系统推送；只在主动打开相关页面时看到“等待家长回应/家长已经回应”。
