# Stage 22：幼儿园故事舞台与亲子现实活动

状态：`IN_PROGRESS`

产品 Phase：全面教学幼儿园深度

需求：REQ-021、REQ-030、REQ-031、REQ-041、REQ-042

## 目标与非目标

为 3–5 岁儿童交付一条可实际使用、可由家长回应的深度教学闭环：App 一次只说明一个短行动，孩子在现实中观察、表达、运动、整理或与家长共读，回来交给家长确认。页面、内容和完成证据必须降低屏幕占用，而不是以更多视频、更长在线时间或小学知识前置为教学深度。

本 Stage 不制作小学以上模板，不开放幼儿园外部网页或推荐流，不采集人脸/声音/位置，不以视频结束、点击按钮或奖励发放冒充掌握，不做连续签到、排行榜、随机奖励、限时施压或抽象金融界面。

## 依据与产品推论

- 教育部《3–6 岁儿童学习与发展指南》覆盖健康、语言、社会、科学、艺术五领域；内容包按五领域组织，但不把领域变成孩子端复杂菜单：<https://www.moe.gov.cn/srcsite/A06/s3327/201210/t20121009_143254.html>
- WHO 建议减少 5 岁以下儿童久坐屏幕活动，并以更积极的玩耍替代；因此单活动预计 3–8 分钟，屏幕只承担说明、短观看和返回确认：<https://www.who.int/publications/i/item/9789241550536>
- AAP 对 2–5 岁强调高质量内容、成人共同观看并帮助迁移到现实世界；因此视频只产生 `VIEWED`，后续仍需现实活动或家长回应：<https://publications.aap.org/pediatrics/article/138/5/e20162591/60503/Media-and-Young-Minds>
- NAEYC 将适龄实践定义为以儿童优势为基础、游戏化并兼顾个体和家庭情境；因此活动提供可理解的小选择和家长支架，不用单一分数给孩子贴标签：<https://www.naeyc.org/resources/position-statements/dap/contents>

以上是产品设计依据，不构成医疗、心理治疗或确定发展效果承诺。

## 两遍视觉与交互规格

### 第一遍：令牌、结构和签名元素

视觉为“可触摸的纸艺舞台”。令牌固定为纸白 `#FFFDF6`、深墨 `#243632`、叶绿 `#4F8A65`、雾绿 `#DDE7DF`、暖阳 `#F3BB45`、边界珊瑚 `#D9786A`。系统无衬线承担正文和按钮；行动标题 28–34sp，按钮 20–22sp，说明至少 17sp。签名元素为三个叶片节点组成的成长路标。

```text
┌──────────────────────────────────────────────┐
│ 成长舞台                                     │
│ 今天：和家长找一片不同形状的叶子             │
│                                              │
│       ① 看看  ──  ② 去做  ──  ③ 给家长看   │
│                                              │
│  现在做                                     │
│  去窗边或院子里，找一片叶子，说说它像什么。  │
│                                              │
│              [ 我去做一做 ]                 │
│                                              │
│ 看完屏幕要去现实中做一做。                  │
└──────────────────────────────────────────────┘
```

### 第二遍：通用感检查与收敛

首稿若保留横向课程轮播、完成百分比、多个活动按钮和奖励数字，会退回通用学习仪表盘。最终幼儿园投影删除活动轮播和量化进度，只显示当前活动；选择题最多同时两个等价选择，普通活动只有一个主按钮。内容超过 8 分钟、选项超过两个或缺短指令时客户端安全停止，并请家长调整，而不是挤入屏幕继续展示。

## 内容、页面与证据边界

| 内容带 | 领域 | 推荐活动 | 证据 | 家长角色 |
| --- | --- | --- | --- | --- |
| 3–4 岁共同体验 | 健康/语言/社会/科学/艺术 | 指一指、模仿动作、听辨、亲子共读、简单整理、观察颜色形状 | `ATTEMPTED` + `PARENT_CONFIRMED`；短视频另记 `VIEWED` | 默认读题、陪同与确认 |
| 5–6 岁准备过渡 | 五领域综合 | 看图说话、两项分类、数现实物品、轮流规则、简单创作 | 可验证活动记 `CHECKED`，现实活动仍需 `PARENT_CONFIRMED` | 逐步减少提示但保持回应 |

每课最多三个连续活动，总预计主动时长不超过 15 分钟；其中屏幕内活动累计目标不超过 8 分钟。至少一个活动必须是亲子或离屏现实活动。`SHORT_VIDEO` 不自动播放，必须可暂停、有视觉进度，并且观看后不直接产生 `MASTERED`。
