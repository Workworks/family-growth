# Stage 23：小学探索手册

状态：`BLOCKED`

产品 Phase：全面教学小学深度

需求：REQ-030、REQ-031、REQ-044、REQ-045、REQ-046、REQ-047、REQ-048、REQ-050

## 目标与非目标

让小学孩子在现有课程事实链上获得真正区别于幼儿园、初中和高中的学习页面：低年级一次读懂并完成一个短活动，高年级能看见“要做/在做/再练”的可解释状态，按“先猜、验证、解释”完成探索，并可随时标记没看懂、暂停向家长求助。

本 Stage 不建设班级、老师端、排名、连续签到、倒计时惩罚或基于同龄人的能力预测；不把年龄当能力诊断。首个纵切不新增服务端年级字段，也不把本机“没看懂”提示冒充持久证据；服务端年级带、求助记录、错因和间隔再练必须在后续工作包另行落地并验收。

## 年级带与安全不变量

- `LOWER_PRIMARY`：通常 6–8 岁，对应一至三年级；一次突出一个活动，使用“读懂 → 试一试 → 说发现”。
- `UPPER_PRIMARY`：通常 9–11 岁，对应四至六年级；显示要做/在做/再练事实和当前探索，但不展示同龄比较。
- 首个 Android 纵切根据家长配置的出生日期计算展示带；解析失败时退回信息更少的低年级视图。该映射只是界面支架，后续服务端年级配置优先于年龄推断。
- 活动完成仍只认 Stage 21 的 `VIEWED/ATTEMPTED/CHECKED/PARENT_CONFIRMED`；“我没看懂”本轮只展开求助建议，不提交 Attempt、不绕过答题或制造完成证据。
- 视频不自动播放、不自动下一集，只按实际播放阈值记录 `VIEWED`；错题使用温和提示和再次尝试，不写“失败”。

## 两遍视觉与交互规格

第一遍采用“可翻的探索夹页”：作业纸白 `#FBFCF7`、铅笔墨 `#263A45`、湖蓝 `#3C7891`、格线蓝 `#CFE0E7`、批注橙 `#D98245`；系统无衬线以字号、字重和小型等宽状态字区分角色。低年级为单张当前页，高年级为三格事实条加当前页；夹页左侧色签是唯一签名元素。

第二遍删除通用仪表盘百分比、横向课程轮播、多张同权卡片和装饰性印章。低年级保留一个主要活动；高年级只增加计划事实和求助出口，不增加奖励数字、排名或持续动效。窄屏内容纵向排列，平板横屏保留清楚留白；Reduced Motion 下无依赖位移的反馈。

```text
低年级：[今天] [学习] [我的]
        ┌ 当前探索夹页 ────────────┐
        │ 读懂 → 试一试 → 说发现  │
        │ 现在只做：……             │
        │        [开始探索]         │
        └───────────────────────────┘

高年级：[今天] [学习] [我的]
        [要做 2] [在做 1] [再练 0]
        ┌ 当前探索：先猜 → 验证 → 解释 ┐
        │ [继续当前一步] [我没看懂]     │
        └───────────────────────────────┘
```

## WP23-3/7 实施契约

- 在 `child_experience_profile` 增加可空 `primary_band_override`，只允许 `LOWER_PRIMARY / UPPER_PRIMARY`；在 `child_experience_audit` 同时记录切换前后值。Flyway 只新增 V13，不修改历史迁移。
- `ExperienceProfile` 在有效学段为 `PRIMARY` 时返回 `recommendedPrimaryBand / primaryBandOverride / effectivePrimaryBand`；非小学学段三者均为空。推荐值按出生日期年龄提供界面支架，家长覆盖优先。
- 只有已鉴权且拥有家庭对象权限的家长可写；覆盖值仅能用于小学有效学段，更新继续使用期望版本，并以审计理由保存。切换学段时可显式清空小学覆盖。
- 更新操作只写体验配置与审计，不级联删除或重写 Stage 21 的 CourseVersion、Assignment、ActivityAttempt、Completion 或 MasteryEvidence。
- Android 优先采用服务端 `effectivePrimaryBand`，旧服务端缺字段时才按出生日期安全回退；家长配置界面提供“按年龄建议 / 一至三年级 / 四至六年级”，孩子端不能修改。
- v0.3.6 使用 `versionCode=12`、既有 applicationId 与稳定 release 证书，通过 tag workflow 生成唯一 APK；不把本地构建或 GitHub 页面存在当作发布完成。
- 服务端家庭课程只投影已发布且与 `effectiveStage` 匹配的版本；Android 另提供明确标为本机的 12 个原创短视频活动。孩子不能浏览草稿、其他学段、答案键、来源 URL 或自行修改学段。学段切换只改变目录投影，不删除旧课程、Assignment、Attempt 或既有本机幼儿园播放记录。
- 家长可为自主课程配置固定 `Money/Coin/XP` 奖励，确认前清楚显示数额；本机升级兼容默认保持 `0 Money / 2 Coin / 5 XP`，未来服务端规则默认必须为零并由家长显式配置。视频活动必须沿用实际播放阈值形成 `VIEWED`，全部必需证据满足后才能完成课程并结算一次；客户端重复、网络重放和并发不得重复发奖。
- Money/Coin 变化必须与不可变 LedgerEntry 在同一事务发生；不接真实支付，不使用随机奖励、连续签到、倒计时或以延长观看时长为目标的刺激。

## WP23-9 实施契约

- Flyway V14 新增每个孩子一条的自主学习奖励策略，以及 Assignment 的 `PARENT/AUTONOMOUS` 来源、Money/Coin/XP 奖励快照和结算标记；历史 Assignment 默认零奖励且不得回填或补发。
- 奖励策略默认 `0 Money / 0 Coin / 0 XP`，只有家长可写；使用期望版本和不可变审计。孩子只读取分配时快照，不能修改策略。
- 自动加入只选择当前服务端 `effectiveStage`、已发布且属于本家庭的最新课程版本，并为其中课节创建缺失 Assignment；数据库唯一约束保证重复同步不重复分配。草稿、旧版本、其他学段、0–2 岁和 `PARENT_ONLY` 不进入儿童目录。
- 自动加入使用显式幂等写端点；GET 目录保持只读。Android 每次同步课程前调用该端点，401/409/网络失败时保留旧目录并显示可恢复状态。
- Assignment 创建时固化当前奖励快照；之后修改策略只影响新 Assignment，避免孩子完成后奖励被静默改变。批准前 API 明确返回快照，家长审核仍使用现有提交/批准状态机。
- 只有状态从 `SUBMITTED` 原子变为 `COMPLETED` 的同一事务可以结算。XP 更新 `child_progress`；Money/Coin 先锁 Wallet，分别写 `LEARNING_REWARD/LEARNING_ASSIGNMENT` LedgerEntry 后更新余额；Assignment 唯一结算标记和账本业务唯一键共同防重复。
- 零奖励仍记录已结算事实但不制造零金额 LedgerEntry。拒绝返工、未达活动证据、重复/不同幂等键重放、并发批准均不得重复入账。

## WP23-4/5 实施契约

- Android 家长备课夹提供 `PRIMARY-PACK-1.0.0` 原创模板：低年级和高年级分别覆盖语文、数学、英语、科学，每个模板有稳定 ID、目标、建议时长、权利依据和现实行动出口；模板只生成草稿，由家长发布，不自动塞入孩子目录。
- 内容避免以刷题和屏幕时长为目标：低年级强调朗读、操作和观察，高年级强调证据、解释和迁移；科学活动使用日常安全材料，不给出危险实验或开放网页。
- Flyway V15 新增不可变 `learning_support_event` 和幂等动作记录。事实类型限定为 `HELP_REQUESTED / INCORRECT_OBSERVED / MISCONCEPTION_CLASSIFIED / REVISIT_SCHEDULED / REVISIT_COMPLETED`，错因只使用具体学习过程类别，不使用能力、人格或同龄比较标签。
- 孩子只能为自己的开放 Assignment/Activity 提交短句求助；求助不写 ActivityAttempt/MasteryEvidence，不改变 Assignment 状态或版本。客观题错误由服务端随 Attempt 同事务写事实，正确重做只在已有到期复习计划时写完成事实。
- 家长可查看本家庭孩子的过程时间线，并对已有求助或错误事实归类、安排 1–30 天后的再练；写操作鉴权、对象权限、幂等，跨家庭按 404 隔离。家长私密说明和答案键不进入儿童投影。
- Android 求助进入现有设备密钥加密 outbox，沿用稳定幂等键；离线和 401 保留，409 刷新事实后由家长处理，不把本地提示冒充已同步。

## WP23-6 实施契约

- 报告只汇总服务端既有小学 Assignment 状态、未回应求助/客观错误、未完成再练和 `usage_event` 中最近 7 天明确标记为 `LEARNING` 的分钟；不生成分数、掌握度、能力/人格标签或同龄比较。
- 仅家长可读，孩子请求返回 403，跨家庭保持 404；响应不得包含答案键、家长私密说明、孩子具体答案或开放来源 URL。
- 学段切换不删除历史，报告继续显示既有小学事实，同时明确返回当前有效学段和可空小学分段；没有事实时返回空列表和 0，不用估算值填充。
- Android 把报告放入既有家长学习回应区，不增加儿童导航；按学科显示完成、待回应、求助、到期再练和已记录分钟，并明确“不是成绩或能力评价”。离线失败保留上次成功事实，不冒充实时数据。
- 本工作包不引入新表、不改变账本与完成状态机。H2/PostgreSQL 必须验证聚合语义、角色/对象权限和敏感字段隔离；Android debug/release JVM、lint、assemble 与目标平板无障碍分别留证。
