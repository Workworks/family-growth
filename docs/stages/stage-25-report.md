# Stage 25：高中自主学习室

状态：`BLOCKED`

产品 Phase：全面教学高中深度

需求：REQ-030、REQ-031、REQ-034、REQ-035、REQ-047、REQ-048、REQ-050；Backlog T-28

## 用户可观察目标

让 15–17 岁孩子在服务端保存的真实选科/模块边界内，把学习组织成“本周目标 → 专题证据 → 阶段复盘 → 下一行动”。孩子可以制定和调整自己的目标、写基于事实的复盘，并明确请求家长支持；系统不输出同龄排名、升学预测、能力标签、风险科目推断或用计时施压。

本 Stage 完成后，家长可配置高中课程模块、从原创模板建立专题/项目并查看投入和支持事实；孩子进入独立的“自主学习室”，看到本周研究板、当前专题与复盘入口。认真完成课程仍沿用固定奖励快照和家长确认结算，不因自评文字、计划偏差或投入时长自动增减奖励。

## 范围内

- 高中课程的必修/选择性必修/选修模块、专题、探究问题、预期证据和安全说明；发布后不可修改。
- 家长配置当前高中学科/模块边界并留审计；孩子只在已启用边界内创建、更新和归档自己的本周目标。
- 孩子基于具体证据写阶段复盘、选择下一策略并请求支持；复盘历史不可覆盖。
- 高中专属 Android “自主学习室”、原创内容包、家长事实报告、H2/PostgreSQL、双变体和治理门禁。

## 范围外

- 高考分数预测、院校推荐、选科收益排名、职业定型、能力画像、同龄比较或自动判定“薄弱/优势学科”。
- AI 代写作业/论文、答案生成、真实考试监考、班级/教师端或把自评当作掌握证据。
- 高风险实验指导、开放网页研究流、第三方视频抽取/缓存/改编或自动播放。
- 完整跨学段迁移、儿童数据导出/删除、强制时段防沉迷与发布总验收；这些归 Stage 26。

## 体验设计（两遍）

页面的具体主题是“高中生安排并复盘一周的专题学习”，单一工作是从真实目标进入当前专题、留下证据并决定下一行动。

第一遍采用“研究工作室”方向：炭墨 `#263238`、松绿 `#3E6B62`、纸白 `#FAFAF7`、档案灰 `#E7ECE9`、证据琥珀 `#C58A2C`、批注蓝 `#41677A`。标题使用系统 Sans 的清晰中粗体，模块/日期/事实编号使用等宽字。宽屏为左侧模块索引、中间本周研究板、右侧证据与复盘；窄屏按“目标—证据—下一行动”纵向折叠。签名元素是“研究板连线”，每一段只连接真实目标、Assignment 或 Reflection。

第二遍删除成绩仪表盘、红黄风险灯、学习时长环、连续计时、徽章和拟物便利贴堆叠；保留安静纸面、一个琥珀当前证据标记和文本按钮。目标调整使用明确的“今天继续 / 本周稍后 / 归档”与版本冲突提示，不依赖拖拽。Reduced Motion 下没有位移动画。

```text
┌ 模块索引 ─┬ 本周研究板 ───────────────────┬ 证据与复盘 ┐
│ 数学 必修  │ 目标：解释导数与变化率        │ 已做事实 2  │
│ 物理 选必  │ 当前专题：从数据建立解释      │ 求助 1      │
│ 历史 选修  │ [继续当前专题] [本周稍后]     │ 下一行动 →  │
└────────────┴───────────────────────────────┴─────────────┘
```

## 安全与事实不变量

1. 高中端提高信息自主性，但不加入无限流、排行榜、连续签到、倒计时惩罚、随机奖励、风险标签或升学预测。
2. 选科/模块边界由家长 RBAC 保护并留不可变审计；孩子不能启用未配置模块。配置变化不删除课程、目标、Attempt、复盘或奖励历史。
3. 每个目标使用 revision 做乐观并发；归档不等于完成课程。目标文字、顺序、自评、求助和投入时长都不能生成 MASTERED 或结算奖励。
4. 复盘只能引用本人的真实 Assignment/目标或明确写“无关联课程”；服务端保存证据摘要、采用策略和下一行动，不保存人格/能力标签。
5. 家长报告只聚合明确状态、学习分钟、目标、求助、再练和复盘数量；“计划偏差”只展示计划与事实差值，不解释原因或评价态度。
6. 内容包全部原创且只生成草稿；外部资料仍走家长批准目录，儿童端不获得原始 URL、广告、评论或推荐流。
7. 固定奖励仍只在家长批准 Assignment 后按快照同事务结算一次；目标/复盘没有 Money/Coin 写入口。
