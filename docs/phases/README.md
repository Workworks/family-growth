# 项目期次文档

Phase 是产品生命周期，Stage 是可独立验收和提交的工程包。完整映射以 [Phase → Stage 实施排期](../program/phase-stage-plan.md)为准。

| Phase | 主题 | 状态 | 入口 |
| ---: | --- | --- | --- |
| 0 | 项目立项与总体设计 | `COMPLETED` | [Phase 0](phase-0/README.md) |
| 1 | 工程骨架与 Family/Growth 基础 | `BLOCKED` | [Phase 1](phase-1/README.md) |
| 2 | 任务提交、审核与奖励 | `COMPLETED` | [Phase 2](phase-2/README.md) |
| 3 | Wallet 与 Ledger | `COMPLETED` | [Phase 3](phase-3/README.md) |
| 4 | 压岁钱、兑换与 Coin | `IN_PROGRESS` | [Phase 4](phase-4/README.md) |
| 5 | 商店、储蓄与愿望 | `NOT_STARTED` | [Phase 5](phase-5/README.md) |
| 6 | 虚拟基金与费用 | `NOT_STARTED` | [Phase 6](phase-6/README.md) |
| 7 | Android 核心页面 | `NOT_STARTED` | [Phase 7](phase-7/README.md) |
| 8 | 跨域闭环与报告 | `NOT_STARTED` | [Phase 8](phase-8/README.md) |
| 9 | V1 发布与总验收 | `NOT_STARTED` | [Phase 9](phase-9/README.md) |

状态只使用 `NOT_STARTED / IN_PROGRESS / COMPLETED / BLOCKED`。计划外 Stage 11（GitHub Release）和 Stage 12（治理）不改变 Phase 0–9 的业务顺序。
