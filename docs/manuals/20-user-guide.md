# Family Growth 用户手册

状态：0.3.8 已发布；v0.3.3 起使用 Android 系统下载服务修复更新长期停在 0%，用户已确认 v0.3.3→v0.3.4 可正常更新；0.3.8 仍待目标平板覆盖升级验收。

## 当前可用

1. 因 v0.3.1 的下载器代码已安装在设备内，无法被远程修复，请手动覆盖安装 `dist/family-growth-0.3.3.apk`（Android 8+），不要卸载、不要清数据、不要混装 debug 包。
2. 手机标题下、平板左侧栏底部都有完整的“孩子视角 / 家长视角”双段按钮；首次进入家长视角需设置 4–8 位 PIN，以后每次进入都需验证。
3. 儿童端从 3 岁开始，只有“今天 / 小任务 / 我的”三个入口；3–5 岁建议家长共同使用。
4. 家长在“任务”创建任务并设置 Money/Coin/XP 奖励；孩子一次只看一个当前任务，完成后交给家长审核，奖励进入钱包与流水。
5. 儿童“我的”可切换“安静小课堂 / 奖励商店”。奖励卡可打开详情并选择“我想要/先不选”；这个动作不扣星星，家长端会看到“孩子想要”。
6. 小课堂包含三个原创离线 18 秒视频，不自动播放；累计实际播放 17 秒后生成待审核任务，家长审核后才发 2 Coin 和 5 XP。
7. 压岁钱、兑换、零钱回收、储蓄和纯模拟基金继续保留在家长管理路径。
8. 家长可设置每日/单次使用分钟数并查看本机今日任务、待审核、App 使用时长和钱包汇总。
9. 宽屏平板显示常驻左侧导航，窄屏显示底部导航；家长端五项、儿童端三项，家长管理区保留 GitHub Release 更新卡片。
10. 新安装的 3–5 岁保守默认值是每日 20 分钟、单次 10 分钟；这是本 App 的产品默认，不替代家庭对总屏幕时间的安排，已有家庭自定义值不会被升级覆盖。
11. v0.3.3→v0.3.4 真机更新已验证；界面会显示排队、连接、下载、暂停或校验，主入口 45 秒无新数据会切换官方备用入口，完成 SHA-256 后交由 Android 系统安装。
12. Stage 17 服务端提供版本化零钱回收规则、十分钟透明报价、申请、家长批准冻结和线下 PAID 确认。批准不立即扣 Money；PAID 才扣账，拒绝/撤销会释放冻结。3–5 岁端不展示复杂费率，由家长共同操作。
13. Stage 20 工程版允许家长设置孩子出生日期，并查看推荐学段；可说明原因后覆盖为幼儿园、小学、初中或高中，也可关闭孩子端触觉反馈。已连接服务时以服务端配置为准，本机未连接时使用明确标识的本地回退。
14. 四个学段使用不同首页：幼儿园是单一主行动的故事舞台，小学是探索手册，初中是学科实验台，高中是自主学习室。幼儿园按钮采用短促、可预测的放大/触觉反馈；关闭系统动画或触觉后会降级。
15. 家长可在服务端维护纪录片权利目录；孩子只会看到符合有效学段、已批准且未过期的条目。外部官方链接不会直接交给孩子打开，原创/授权离线内容也必须使用受控内容引用。
16. Stage 21 工程版在小学、初中和高中孩子端“学习”页增加“我的任务 / 自主学习”切换。学段由家长配置锁定，孩子可选择年级、学科、教材版本和册次，再手动进入国家中小学智慧教育平台官方同步课堂；幼儿园阶段不开放外部网页自主学习。
17. 已核验的“小学·一年级·语文·统编版·上册”会打开用户提供的精确官方页面，其他组合先打开官方同步课堂选择页继续选择。网页不自动播放、不允许输入任意网址，也不会把观看时长自动换成任务完成、奖励或钱包变化。
18. Stage 21 工程版家长中心新增“免费教育资源书架”。连接家庭服务后可添加 HTTPS 来源、选择小学/初中/高中、填写免费使用说明，然后依次“读取栏目 → 批准展示”。孩子自主学习页会动态显示已批准的来源和栏目名称，但不接收网址；点击栏目会提示请家长一起打开。
19. Stage 23 工程版允许家长在小学阶段进一步选择“一至三年级 / 四至六年级 / 按年龄建议”。连接家庭服务时该值由服务端保存并审计；切换不会删除历史课程或尝试记录。孩子自主学习页优先显示当前有效学段的家庭课程。
20. 本机安静小课堂为幼儿园、小学、初中、高中各提供 3 个不同年龄表达的原创短视频活动。连接家庭服务后，家长保存的固定 Money/Coin/XP 规则会进入服务端；孩子刷新时自动加入当前有效学段、每门课程最新已发布版本的课节。奖励在加入时固化，实际播放达到 90% 且全部步骤完成、再由家长批准后，才由服务端一次性写入 XP、钱包与流水。规则后改不追溯旧课，幼儿园只显示“小星星/请家长一起”等简单表达。
19. Stage 21 V11 工程版已接通服务端课程：家长通过生产 API 创建/发布课程后，孩子在现有“小任务”页看到“学习路径”而不会增加一级导航。进行中的课节始终是当前唯一主要行动，普通任务会暂存在“后来再做”。选择、配对、排序、亲子阅读、口头和线下活动逐步完成；安装包内已审核短视频只累计实际播放，达到 90% 才记录 `VIEWED`。完成孩子侧步骤后交给家长确认；若家长要求温和复做，孩子必须重新尝试至少一步才可再次提交。只有家长批准且该 Assignment 带有固定奖励快照时才结算一次。
20. Stage 21 V12 工程版在家长页加入“家庭备课夹”：连接服务后按“写一课 → 发布 → 布置”创建当前学段的一课一活动。可选择亲子共读、现实行动或安装包原创短片；草稿发布后不可原地修改。0–2 岁只由家长记录现实成长，不创建孩子屏幕课程。
21. 孩子完成学习步骤时会先把最小动作加密保存在本机，再连接服务。断网会显示“已经安全记下”；会话过期时待办仍保留，家长重新连接同一家庭/孩子后可“刷新并合并”。无法自动解释的冲突不会静默覆盖，必须由家长处理。
22. 连接家庭服务后，礼金、兑换、奖励订单审核、储蓄、愿望、模拟基金、零钱回收和今日/月报都由服务端裁决；兑换、基金和零钱回收会先显示费率、费用与预计到账，再允许确认。未连接时只进入明确标注的本机演示，网络失败不会伪装成本机成功。
23. 防沉迷除每日上限与睡眠时段外，还执行服务端单次连续会话和强制休息。跨午夜、延迟上报或重复事件不能重置休息；家长可在隐私中心配置 30–365 天的非财务明细保留期并立即执行清理，账本与必要审计不会被自动删除。
24. Stage 27 工程版在家长“成长”页加入低刺激的“家庭成长年轮”：可建立一个现实成长计划、记录当天可观察的具体动作，并可从系统相册附加不超过 5 MiB 的 JPEG/PNG/WebP。照片只允许家长会话读取，服务端核验真实格式并使用 `no-store` 响应；孩子端不增加档案入口。
25. 成长报告只汇总进行中/完成计划、真实记录和照片数量，不产生分数、连续天数、排行榜、人格标签或能力推断。0–2 岁使用亲子阅读、运动、语言、自理和情感连接的家长记录模板，不建立孩子屏幕任务。

## 当前尚未深化

当前稳定发布包是 0.3.8/14，包含 Stage 20–26 的四学段教学、动态学习路径、加密 outbox、家长备课、适龄原创课程、数据导出/受约束删除、自动保留、服务端强制休息和生产财商/报告接入。Stage 27 成长年轮仍是未发布工程能力。现有能力仍未在目标平板真实验证页面加载、视频播放、AndroidKeyStore、杀进程、断网、横竖屏、TalkBack、物理触觉和 v0.3.7→v0.3.8 数据保留；这些设备项不能由构建测试代替。家庭备课夹仍以安全模板和家长审核为边界，不是开放网页抓取器或无限内容平台。

自定义来源只识别静态 HTML 导航；依赖 JavaScript、必须登录、跨域跳转或阻止自动访问的网站可能显示“读取失败”。失败时 App 保留最近一次成功栏目，家长可稍后重试或改填该站稳定的栏目首页。该功能不会复制站点正文或视频，也不会自动判断内容是否适龄，批准前仍需家长检查。

## 安全提示

- 当前稳定包使用专用 release 证书；debug 包与 release 包签名不同，Android 不允许直接互相覆盖。
- PIN 只保护当前设备；业务数据保存在 App 私有本地存储，不等同于生产服务端安全。
- 不要把 PIN、签名私钥、GitHub Token 或儿童敏感资料发送到聊天或提交到 Git。
- 钱包和基金是家庭内部教育模拟，不代表真实资金或投资。
- 防沉迷只统计并阻断本 App 的孩子模式，不控制平板上的其他 App。
- 官方同步课堂内容直接由 `basic.smartedu.cn` 页面提供；App 不下载、抽取、代理、转码或改编其视频，也不保证第三方页面永久可用。
