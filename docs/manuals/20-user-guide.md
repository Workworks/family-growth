# Family Growth 用户手册

状态：0.2.1 稳定签名基础体验版。代码、单测/lint、两版 GitHub Release 和公开 digest 已完成；因缺少可用 Android 设备，尚未完成安装后的运行态验收。

## 当前可用

1. 首次安装 `dist/family-growth-0.2.0.apk`（Android 8+）作为稳定签名基线；不要先装同版本 debug 包。
2. 首次点击“家长验证”，设置 4–8 位数字的本机 PIN；返回孩子模式后再次进入需验证 PIN。
3. 家长在“任务”创建任务并设置 Money/Coin/XP 奖励；孩子提交后，家长审核，奖励进入钱包与流水。
4. 家长可按基础比例 1:1 存入压岁钱；孩子可兑换 Coin、兑换家庭奖励、储蓄、记录愿望和买卖纯模拟基金。
5. 孩子申请零钱回收时先看到 2% 手续费与预计到账；提交不扣款，家长确认后才扣款并形成流水。
6. 家长可设置每日/单次使用分钟数并查看本机今日任务、待审核、App 使用时长和钱包汇总。
7. 宽屏平板显示常驻左侧导航，窄屏显示五项底部导航；家长管理区保留 GitHub Release 更新卡片。
8. 在 0.2.0 家长管理区检查更新，应发现 0.2.1；下载的 APK 通过 GitHub digest 后交由 Android 系统确认安装。

## 当前尚未深化

服务端登录/RBAC、多设备同步、复杂规则、图片凭证、通知、系统级跨 App 防沉迷、真实金融和复杂报表均不在本机基础版内。GitHub Release 和稳定签名已完成，真机覆盖升级仍待设备验收。

## 安全提示

- 当前稳定包使用专用 release 证书；debug 包与 release 包签名不同，Android 不允许直接互相覆盖。
- PIN 只保护当前设备；业务数据保存在 App 私有本地存储，不等同于生产服务端安全。
- 不要把 PIN、签名私钥、GitHub Token 或儿童敏感资料发送到聊天或提交到 Git。
- 钱包和基金是家庭内部教育模拟，不代表真实资金或投资。
- 防沉迷只统计并阻断本 App 的孩子模式，不控制平板上的其他 App。
