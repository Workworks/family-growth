# Family Growth 用户手册

状态：0.3.4；v0.3.3 起使用 Android 系统下载服务修复更新长期停在 0%，用户已确认 v0.3.3→v0.3.4 可正常更新。

## 当前可用

1. 因 v0.3.1 的下载器代码已安装在设备内，无法被远程修复，请手动覆盖安装 `dist/family-growth-0.3.3.apk`（Android 8+），不要卸载、不要清数据、不要混装 debug 包。
2. 手机标题下、平板左侧栏底部都有完整的“孩子视角 / 家长视角”双段按钮；首次进入家长视角需设置 4–8 位 PIN，以后每次进入都需验证。
3. 儿童端从 3 岁开始，只有“今天 / 小任务 / 我的”三个入口；3–5 岁建议家长共同使用。
4. 家长在“任务”创建任务并设置 Money/Coin/XP 奖励；孩子一次只看一个当前任务，完成后交给家长审核，奖励进入钱包与流水。
5. 儿童“我的”可切换“安静小课堂 / 奖励商店”。奖励卡可打开详情并选择“我想要/先不选”；这个动作不扣星星，家长端会看到“孩子想要”。
6. 小课堂包含三个原创离线 18 秒视频，不自动播放；累计实际播放 17 秒后生成待审核任务，家长审核后才发 2 Coin 和 5 XP。
7. 压岁钱、兑换、零钱回收、储蓄和纯模拟基金继续保留在家长管理路径。
8. 家长可设置每日/单次使用分钟数并查看本机今日任务、待审核、App 使用时长和钱包汇总。
9. 宽屏平板显示常驻左侧导航，窄屏显示底部导航；家长端五项、儿童端三项，家长管理区保留 GitHub Release 更新卡片。
10. 新安装的 3–5 岁保守默认值是每日 20 分钟、单次 10 分钟；这是本 App 的产品默认，不替代家庭对总屏幕时间的安排，已有家庭自定义值不会被升级覆盖。
11. v0.3.3→v0.3.4 真机更新已验证；界面会显示排队、连接、下载、暂停或校验，主入口 45 秒无新数据会切换官方备用入口，完成 SHA-256 后交由 Android 系统安装。
12. Stage 17 服务端提供版本化零钱回收规则、十分钟透明报价、申请、家长批准冻结和线下 PAID 确认。批准不立即扣 Money；PAID 才扣账，拒绝/撤销会释放冻结。3–5 岁端不展示复杂费率，由家长共同操作。
13. Stage 20 工程版允许家长设置孩子出生日期，并查看推荐学段；可说明原因后覆盖为幼儿园、小学、初中或高中，也可关闭孩子端触觉反馈。已连接服务时以服务端配置为准，本机未连接时使用明确标识的本地回退。
14. 四个学段使用不同首页：幼儿园是单一主行动的故事舞台，小学是探索手册，初中是学科实验台，高中是自主学习室。幼儿园按钮采用短促、可预测的放大/触觉反馈；关闭系统动画或触觉后会降级。
15. 家长可在服务端维护纪录片权利目录；孩子只会看到符合有效学段、已批准且未过期的条目。外部官方链接不会直接交给孩子打开，原创/授权离线内容也必须使用受控内容引用。
16. Stage 21 工程版在小学、初中和高中孩子端“学习”页增加“我的任务 / 自主学习”切换。学段由家长配置锁定，孩子可选择年级、学科、教材版本和册次，再手动进入国家中小学智慧教育平台官方同步课堂；幼儿园阶段不开放外部网页自主学习。
17. 已核验的“小学·一年级·语文·统编版·上册”会打开用户提供的精确官方页面，其他组合先打开官方同步课堂选择页继续选择。网页不自动播放、不允许输入任意网址，也不会把观看时长自动换成任务完成、奖励或钱包变化。

## 当前尚未深化

当前稳定发布包仍是 0.3.4；Stage 20/21 属于工程代码，尚未制作新的稳定 Release。国家智慧教育平台入口已通过 JVM/lint/build，但还未在目标平板真实验证页面加载、播放、站内跳转、返回和 TalkBack。完整 Course/Unit/Lesson/Activity、题库、掌握度、内容包下载和各学段深度课程属于 Stage 21–25，不能把四套首页骨架、目录条目或外部网页入口当作已完成教学引擎。图片凭证、通知、系统级跨 App 防沉迷、真实金融和复杂报表也未深化。

## 安全提示

- 当前稳定包使用专用 release 证书；debug 包与 release 包签名不同，Android 不允许直接互相覆盖。
- PIN 只保护当前设备；业务数据保存在 App 私有本地存储，不等同于生产服务端安全。
- 不要把 PIN、签名私钥、GitHub Token 或儿童敏感资料发送到聊天或提交到 Git。
- 钱包和基金是家庭内部教育模拟，不代表真实资金或投资。
- 防沉迷只统计并阻断本 App 的孩子模式，不控制平板上的其他 App。
- 官方同步课堂内容直接由 `basic.smartedu.cn` 页面提供；App 不下载、抽取、代理、转码或改编其视频，也不保证第三方页面永久可用。
