# 39 四学段教学体验与内容分层

文档性质：`PRODUCT_AND_UX_BASELINE`

日期：2026-08-26

关联需求：REQ-021、REQ-028、REQ-030、REQ-031

## 1. 目标与边界

Family Growth 的教学能力按幼儿园、小学、初中、高中四个学段分别呈现。分层不只是换颜色：课程目标、活动类型、页面结构、语言密度、反馈强度、家长参与和财商可见范围都必须变化。

年龄只用于推荐学段，不用于给孩子贴能力标签。家长可以按实际入学、发展节奏或特殊需要覆盖推荐结果；覆盖不删除历史进度，也不自动提高难度。0–2 岁只有家长记录模式，不开放儿童自主操作；18 岁及以上不属于当前儿童端范围。

本设计遵循儿童最佳利益优先：有趣不等于高刺激，明显反馈不等于持续震动，纪录片不等于无限视频流，教学完成不等于只把视频播到结尾。

## 2. 年龄、学段与配置模型

### 2.1 默认映射

| 学段代码 | 默认年龄 | 推荐页面 | 家长角色 | 变体 |
| --- | ---: | --- | --- | --- |
| `KINDERGARTEN` | 3–5 | 故事舞台 | 默认共同使用、读题与回应 | 3–4、5–6 岁内容带 |
| `PRIMARY` | 6–11 | 探索手册 | 选课、排课、查看困难点 | 低年级 1–3、高年级 4–6 |
| `JUNIOR_MIDDLE` | 12–14 | 学科实验台 | 共同定目标、减少过程干预 | 初一、初二、初三 |
| `SENIOR_HIGH` | 15–17 | 自主学习室 | 提供边界和复盘支持 | 高一、高二、高三 |

中国各地入学年龄和孩子发展节奏不同，因此默认年龄映射只产生 `recommendedStage`，最终使用 `effectiveStage`。

### 2.2 家长配置

家长端“孩子资料 → 学习阶段”提供：

- 年龄或已有出生日期；若已有完整出生日期，不重复采集。
- 系统推荐学段及推荐理由。
- 学段覆盖选项、覆盖原因和生效日期。
- “下学期再提醒”而不是自动切换。
- 切换前预览会出现、隐藏和保持不变的页面与内容。

服务端是学段事实源。建议字段为 `recommendedStage`、`stageOverride`、`effectiveStage`、`effectiveFrom`、`overrideReason`、`updatedBy`、`updatedAt`；变更写审计事件。只有 `PARENT` 可修改，孩子端只读取。修改学段不重算既有奖励、不删除学习记录、不把未完成课程强行标成完成。

### 2.3 页面路由契约

Android 登录或同步后取得 `AgeExperienceProfile`：

- `effectiveStage`：四学段之一。
- `gradeBand`：学段内细分，可为空。
- `feedbackProfile`：动效、声音、触觉和 Reduced Motion 结果。
- `visibleCapabilities`：允许展示的页面能力，不由客户端凭年龄自行猜测。
- `contentPolicy`：允许的年龄评级、语言、时长、在线/离线和家长陪同条件。
- `profileVersion`：支持缓存、迁移和服务端变更同步。

离线时使用最后一次签名/校验成功的配置；从未同步成功则进入最保守的幼儿园低刺激演示页，不暴露金融和外链能力。

## 3. 四学段产品设计

### 3.1 幼儿园：故事舞台

设计意图是“孩子看得懂下一步并愿意去现实中做”，不是把注意力锁在屏幕上。

| 维度 | 方案 |
| --- | --- |
| 一级导航 | `今天`、`发现`、`我的`，固定 3 个 |
| 首屏 | 一个大场景、一项主要活动、最多两个同级选择 |
| 核心领域 | 健康、语言、社会、科学、艺术，映射教育部 3–6 岁指南；不做小学知识前置竞赛 |
| 活动 | 亲子共读、看图说话、数一数、听辨、配对、模仿动作、整理、观察自然、情绪表达 |
| 完成证据 | 家长确认、简短选择/配对、现实行动反馈；视频结束只算“看过” |
| 单次内容 | 3–8 分钟；视频后优先给离屏观察或亲子提问 |
| 财商 | 星星、存起来、想要的东西、请家长一起；不出现 NAV/费率/交易 |

视觉方向为“可触摸的纸艺故事舞台”。主背景使用纸白 `#FFFDF6`，主要行动使用叶绿 `#4F8A65`，快乐确认使用暖阳 `#F3BB45`，辅助天空 `#CDEAF3`，边界珊瑚 `#D9786A`，正文深墨 `#243632`。签名元素是“成长舞台”：任务卡像一张打开的纸艺小舞台，完成后舞台中的叶片舒展一次，然后引导孩子离屏或请家长回应。

所有可点击控件必须有清楚的按下态，但只有主要动作和明确成功使用强化反馈：

- 普通按钮：按下缩放到 `0.96`，抬起回到 `1.00`，总时长不超过 180ms；一次系统允许的轻触觉确认。
- 主要动作：`1.00 → 1.10 → 0.98 → 1.00`，总时长 240–320ms；颜色填充和轮廓同步变化。
- 成功：最多两次短触觉脉冲，一次叶片舒展；不撒随机奖励、不循环、不遮挡“下一步”。
- 错误：不使用强烈震动；控件轻微左右移动一次并给出“再试一次/请家长帮忙”。
- 系统关闭触觉、家长关闭触觉或 Reduced Motion 生效时，取消震动和缩放弹跳，改为静态描边/填充变化。核心含义不得依赖声音、颜色或动画。

### 3.2 小学：探索手册

小学阶段在趣味和结构之间建立桥梁。低年级继续使用更多图形与朗读，高年级逐步增加文字、步骤和自我检查。

| 维度 | 方案 |
| --- | --- |
| 一级导航 | `今天`、`学习`、`我的` |
| 首屏 | 今日计划、一个推荐起点、可展开的 3–5 项清单 |
| 学科 | 语文、数学、英语、科学、道德与法治、体育与健康、艺术、劳动与综合实践 |
| 活动 | 朗读、听写辅助、计算、看图推理、实验观察、阅读理解、错题重做、现实项目 |
| 反馈 | 明显但不夸张；一次状态变化和轻触觉，答错说明线索而非人格评价 |
| 报告 | 学了什么、哪里需要再练、实际时长、家长回应；不做班级排行 |

视觉方向为“探索手册”：纸张分区、学科标签和可收起的步骤卡。色彩比幼儿园克制，保留叶绿与暖阳，增加蓝墨 `#355C7D`。签名元素是“探索印章”，仅在完成一项明确活动后盖一次固定印章，不形成集章连续签到。

低年级默认一次展示一个活动步骤；高年级允许课程目录和简单进度。练习完成至少结合答案、口头/书面作品或家长确认，不能只按打开时长发奖。

### 3.3 初中：学科实验台

初中阶段重点从“完成任务”转为“理解知识点、发现问题、安排复习”。

| 维度 | 方案 |
| --- | --- |
| 一级导航 | `计划`、`学科`、`复盘` |
| 首屏 | 今日负担、优先级、预计时间和可调整顺序 |
| 学科 | 语文、数学、英语、物理、化学、生物、历史、地理、道德与法治、体育艺术劳动 |
| 活动 | 章节学习、知识点练习、实验任务、阅读与史料分析、错因标记、间隔复习 |
| 反馈 | 克制的状态过渡；触觉只用于确认、提交和重要警告 |
| 自主性 | 学生可调整同日任务顺序、标记“没看懂”和申请家长/老师协助 |

视觉方向为“安静实验台”：深蓝绿 `#294C53`、雾蓝 `#DDE8EA`、琥珀 `#D8A23B` 和纸白。签名元素是“知识路径线”，显示章节、尝试和复做证据，不显示同龄比较。错题本记录题目版本、错误类型、使用提示和再次尝试，不只存最终分数。

专注计时由学生主动开启，可以暂停和结束；不设置强制倒计时、失败惩罚或连续天数。系统建议复习时说明依据，并允许忽略。

### 3.4 高中：自主学习室

高中阶段强调目标、选择、深度学习、学科核心素养和现实规划，不把产品缩减成刷题计时器。

| 维度 | 方案 |
| --- | --- |
| 一级导航 | `目标`、`课程`、`复盘` |
| 首屏 | 本周目标、今日投入、风险科目和可解释的下一建议 |
| 学科 | 按高中课程方案配置必修/选择性必修/选修，兼容不同选科组合 |
| 活动 | 模块课程、专题阅读、实验探究、项目研究、知识网络、错题归因、阶段自评 |
| 反馈 | 最少装饰动效；触觉只用于提交和高风险操作确认 |
| 自主性 | 学生可制定/调整计划、选择复习策略、查看数据来源；家长关注边界和支持 |

视觉方向为“学习工作室”：炭墨 `#263238`、纸白 `#FAFAF7`、松绿 `#3E6B62`、少量琥珀。签名元素是“本周研究板”，将目标、证据和下一行动连接起来。报告展示完成、掌握、复做、真实投入和计划偏差，不提供羞辱性红榜、排名或预测性标签。

高中财商可以展示预算、费用、模拟波动和账本明细，但所有基金仍为家庭内部模拟；费用透明且不做收益推荐。

## 4. 共用教学与内容架构

四学段共享同一领域模型，页面通过学段能力配置变化，不能复制四套彼此漂移的数据：

`Subject → Course → Unit → Lesson → Activity → Attempt → MasteryEvidence`

每个内容版本至少包含：学段/年级带、学习目标、预计主动时长、活动类型、完成判定、家长参与度、语言、无障碍资源、来源/授权、发布状态和撤回原因。历史 Attempt 永远引用当时版本。

完成状态至少区分：

- `VIEWED`：看过或播放达到门槛。
- `ATTEMPTED`：做过一次活动。
- `CHECKED`：系统可验证题型已核对。
- `PARENT_CONFIRMED`：现实活动由家长确认。
- `MASTERED`：达到明确目标且留有证据。
- `REWORK_REQUIRED`：需要再练，不使用“失败”。

奖励绑定“明确活动及其完成证据”，视频播放只能产生 `VIEWED`；是否进一步完成由内容规则决定。

## 5. 纪录片来源与版权策略

### 5.1 来源等级

| 等级 | 可进入方式 | 要求 |
| --- | --- | --- |
| `ORIGINAL_OFFLINE` | 随内容包离线播放 | 项目原创，保留脚本、素材来源、字幕和版本证据 |
| `LICENSED_OFFLINE` | 下载到受校验内容包 | 每一条有明确授权、地域/期限/修改范围和署名；摘要校验、可撤回 |
| `OFFICIAL_LINK` | 家长批准后打开官方页面/应用 | 不下载、不去广告、不解析媒体直链；儿童端不进入开放浏览器和推荐流 |
| `PROHIBITED` | 不展示 | 来源不明、盗链、含广告追踪、自动推荐、评论区或授权不清 |

### 5.3 年龄与播放门禁

- 家长端可预览、启用/停用、设置每天视频上限并查看来源与授权。
- 儿童端只看到已启用且符合 `effectiveStage` 的条目；不提供 URL 输入、搜索全网或跳转评论区。
- 不自动播放、不自动下一集、不无限滚动；结束页首先给出一个现实观察、讨论或小练习。
- 幼儿园纪录片默认亲子共看；快速剪辑、恐怖捕食、灾害细节和高强度音效需要单独年龄审查。
- 播放进度可恢复，但不以“看完更多”作为推荐目标。

## 6. 家长端教学工作台

家长端按“孩子 → 学段 → 内容 → 计划 → 反馈”组织：

1. 配置年龄和学段，预览儿童页面。
2. 选择学科/发展领域与本周目标。
3. 从已审核内容中启用课程、纪录片和现实活动。
4. 设置每天总时长、视频时长、奖励上限和家长确认方式。
5. 查看 `VIEWED/ATTEMPTED/CHECKED/PARENT_CONFIRMED/MASTERED` 的真实证据。
6. 根据“需要再练/需要帮助”调整计划，不比较其他儿童。

## 7. 可访问性与验收门禁

- 四个学段均必须有不同的信息架构和交互密度，不能只切换主题色。
- CHILD 一级导航始终不超过 3 个；幼儿园首屏只有一个主要行动。
- 家长年龄/学段修改必须通过认证授权并写审计，孩子端修改请求必须被服务端拒绝。
- 幼儿园所有点击有可见按下态；主要反馈不超过 320ms，不循环，触觉可关闭并尊重系统设置。
- Reduced Motion 下删除缩放/弹跳/装饰位移，保留静态状态变化；TalkBack 能读出控件、进度和完成结果。
- 所有纪录片条目有来源、年龄、语言、时长、权利等级、审核人、审核时间和撤回状态；无权利记录不得发布。
- 外部来源失败或被下架时安全移除，不影响历史学习记录。
- 平板横屏、窄屏、字体放大、离线恢复、学段切换和内容撤回必须进入自动化与真机验收。

## 9. 不在本设计中承诺

- 不承诺任何第三方视频已经获得离线分发、剪辑或中文配音授权；必须逐条完成权利审查。
- 不把年龄自动映射当作能力诊断，不代替教师、家长或专业人员判断。
- 不建设公开内容上传、开放网页搜索、社交评论、班级排行榜或基于观看时长的推荐流。
- 本文是后续 Stage 的产品与 UX 基线，不代表四学段页面、后端模型或纪录片内容已经实现。
