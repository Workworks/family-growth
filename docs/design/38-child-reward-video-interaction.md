# 儿童奖励浏览与教学视频交互设计

## 1. 设计对象与单一目标

对象是 3 岁起、默认与家长共同使用平板的孩子。页面单一目标是：孩子清楚地选择“先看一个短教学视频”或“看看家庭奖励”，完成后把结果交给家长回应，而不是延长屏幕停留。

## 2. 视觉与布局方向

- 调色沿用家庭成长品牌：松叶绿 `#2F6D5A`、嫩芽绿 `#8DBF8A`、暖阳黄 `#E8B04A`、纸张白 `#FFFDF7`、石板灰 `#40534D`。
- 角色切换使用固定双段式“孩子视角 / 家长视角”，不再把当前视角藏进顶栏小 Chip；每段至少 48dp，高亮只表达当前状态。
- 奖励卡片使用“家庭心愿标签”作为识别特征：大图形、短标题、明确 Coin 价格和一个可撤销的“我想要”动作；不使用无限滚动、抢购、库存焦虑或闪烁动画。
- 教学视频使用“安静小课堂”卡片：清楚显示主题、时长和已观看状态；播放器不自动播放、不连播，随时可暂停和退出。

## 3. 行为边界

1. 儿童一级导航继续限制为三个；奖励商店和教学视频嵌入既有入口，不增加第四入口。
2. 孩子在奖励商店只能浏览详情和表达/撤销兴趣，不能直接扣 Coin、下单或绕过家长审核。
3. 教学视频是原创、本地离线、无广告、无推荐流、无追踪内容，不从开放视频平台嵌入儿童不可控内容。
4. 播放不自动开始；只累计真实处于播放状态的时长，拖动进度条不能直接完成。
5. 累计播放达到视频时长 90% 后，把对应任务置为 `SUBMITTED`；奖励在家长审核后才进入账本。
6. 完成文案描述行动：“这节看完了，等家长确认”，不以聪明、排名或连续观看评价孩子。

## 4. 交互状态

| 能力 | 空状态 | 进行中 | 完成/恢复 |
| --- | --- | --- | --- |
| 奖励浏览 | 家长尚未添加时提示“一起请家长添加奖励” | 点卡片看详情；“我想要”可立即撤销 | 家长视角显示孩子感兴趣的标记 |
| 教学视频 | 内置课程始终可见，不依赖网络 | 显示累计观看进度，可暂停/退出 | 90% 后只提交一次任务，重启后保持完成 |
| 视角切换 | 始终显示当前视角 | CHILD→PARENT 弹 PIN；PARENT→CHILD 直接切换 | 切换失败保持原视角并给出具体提示 |

## 5. 验收重点

- 手机和平板不截断“孩子视角 / 家长视角”，两段均满足大触控目标。
- 孩子一级导航仍为三项，无随机奖励、倒计时、自动播放、连播和复杂费率。
- 奖励兴趣不产生账本分录；视频达到阈值只产生待家长审核任务，审核前余额不变。
- 本地持久化兼容旧版状态，更新到新 APK 不清除已有家庭数据。
