# Family Growth 基础体验视觉与信息架构

## 1. 设计对象与单一任务

对象：使用 Android 平板共同管理学习、成长任务和家庭虚拟经济的家长与孩子。

单一任务：用户打开 App 后，在一个屏幕内看清“今天要做什么、已经成长多少、还能使用多久、奖励去了哪里”。

参考 `E:\test\DiaperTracker` 的视觉语言和组织方式，不复制其资产/收纳业务内容。

## 2. 视觉令牌

| 角色 | 名称 | Hex | 用途 |
| --- | --- | --- | --- |
| Primary | 成长翡翠 | `#087A57` | 主按钮、选中导航、成长进度 |
| Primary surface | 新芽薄荷 | `#E8F7F0` | 选中状态、正向卡片 |
| Accent | 奖励琥珀 | `#F2A640` | Coin、提醒、今日重点 |
| Canvas | 晨雾灰 | `#F4F7F5` | 全局背景 |
| Ink | 森林墨 | `#10231C` | 标题与主正文 |
| Slate | 苔石灰 | `#607069` | 次要文字与边界 |
| Danger | 珊瑚红 | `#D95757` | 限时、拒绝和余额不足 |

字体角色：展示标题使用系统 Serif/Fallback，形成“成长手册”质感；正文使用系统 Sans；余额、时长、NAV 和流水数字使用 Monospace。避免所有文本使用同一默认字重。

圆角：主卡 28dp、普通卡 20dp、Chip 14dp。卡片采用 1dp 冷灰描边和极低阴影，不堆叠浮夸渐变。

## 3. 布局方案

平板：左侧 216dp 导航 Rail，右侧内容采用 12 列感知的双栏卡片；关键总览占主列，任务/提醒占次列。

```text
┌──────────────┬────────────────────────────────────────┐
│ Family       │  今天，一起成长      孩子/家长状态      │
│ Growth       │ ┌────────成长环────────┐ ┌─今日任务────┐ │
│              │ │ 任务完成 / 用时 / 奖励│ │ 待办与提交  │ │
│ ● 今日       │ └─────────────────────┘ └─────────────┘ │
│ ○ 任务       │ ┌────────钱包──────────┐ ┌─最近流水────┐ │
│ ○ 钱包       │ └─────────────────────┘ └─────────────┘ │
│ ○ 成长       │                                        │
│ ○ 家长       │                                        │
└──────────────┴────────────────────────────────────────┘
```

窄屏：顶部保留轻量状态，内容单列，底部五栏导航；主要创建动作放页面内，不使用遮挡内容的全局 FAB。

## 4. 签名元素：成长环

首页使用三层不闭合的同心成长环，分别编码任务完成率、今日 App 内用时和奖励目标。它来自儿童成长“年轮/轨道”的真实隐喻，不是装饰圆环；中心只显示今天最重要的一个数字。整个 App 的大胆设计只花在此处，其余卡片保持安静。

## 5. 五个工作区

| 工作区 | 核心内容 |
| --- | --- |
| 今日 | 成长环、今日摘要、下一任务、钱包快照、使用时长 |
| 任务 | 新建、待完成、已提交、审核、奖励结果 |
| 钱包 | Money/Coin/XP、压岁钱、兑换、提现预览、流水 |
| 成长 | 奖励商店、储蓄、愿望、纯模拟基金和收益复盘 |
| 家长 | 本机 PIN、防沉迷规则、今日报告、更新与基础设置 |

## 6. 参考转译与自我评审

保留参考项目有效之处：翡翠/琥珀/Slate、描边卡、五区导航、清晰空态、分组设置和紧凑数据层级。

主动舍弃：密集 Emoji 工具箱、过多入口、首页功能堆叠和资产管理语汇。首版设计草案曾准备直接复用普通“统计卡 + 大数字”，这会成为任何仪表盘都能使用的模板；已改为同时编码任务/时长/奖励的成长环，并让结构服务本项目核心闭环。

## 7. 动效与文案

- 本机基础版保持即时、稳定的静态切换，不加入可能影响儿童专注的循环动效；后续若增加数据过渡，必须尊重系统 Reduced Motion。
- 按钮使用明确动词：“提交任务”“审核并发放”“存入压岁钱”“购买模拟份额”。
- 空状态给出下一动作，不使用“暂无数据”后结束。
- 错误说明原因和修复方式；余额不足、PIN 错误、更新源未配置均不静默。
