# 36 儿童端发展与行为设计基线

## 1. 目标与证据边界

儿童端从 3 岁开始。设计目标不是让孩子更久地停留在屏幕里，而是帮助孩子看懂一个小行动、去现实中完成、回来交给家长回应，并逐步形成可迁移的自我调节能力。

本基线借鉴发展心理学、执行功能支架、亲子响应互动、健康屏幕使用和儿童适龄设计原则，但不把界面效果表述为医疗、心理治疗或确定的成长结果。家长仍需按孩子的个体发展、家庭节奏和专业建议调整。

主要外部依据：

- American Academy of Pediatrics：2–5 岁使用高质量内容并由成人共同观看/解释，避免快速、分散注意力的内容；<https://publications.aap.org/pediatrics/article-abstract/138/5/e20162591/60503/Media-and-Young-Minds>
- WHO：3–4 岁久坐屏幕时间不超过 1 小时且越少越好，静坐时鼓励与照护者阅读和讲故事；<https://www.who.int/news/item/24-04-2019-to-grow-up-healthy-children-need-to-sit-less-and-play-more>
- Harvard Center on the Developing Child：3–5 岁执行功能需要与能力匹配的活动、成人支架和逐步撤除支持；亲子“serve and return”回应支持早期语言与社会能力；<https://developingchild.harvard.edu/resources/handouts-tools/activities-guide-enhancing-and-practicing-executive-function-skills/>、<https://developingchild.harvard.edu/key-concept/serve-and-return/>
- ICO Children’s Code：低龄儿童需要明确规则、更高家长支持、高隐私默认和休息工具，不得利用心理偏差诱导不利选择；<https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/childrens-information/childrens-code-guidance-and-resources/age-appropriate-design-a-code-of-practice-for-online-services/13-nudge-techniques/>

## 2. 年龄分层

| 年龄 | 儿童端呈现 | 成人角色 | 财商语言 |
| --- | --- | --- | --- |
| 3–5 | 一次一个任务；图形+短句；稳定反馈；最多两个并列选择 | 默认共同使用，读题、确认完成、回应孩子 | 星星、存起来、想要的东西；不直接展示基金/NAV/费率/流水 |
| 6–9 | 可查看短任务清单和简单进度；仍保持三入口 | 设置规则、审核、共同复盘 | 零花钱、储蓄、兑换；交易前仍需家长托底 |
| 10–12 | 增加原因、费用和选择后果解释 | 引导孩子说出取舍 | 预算、费用、模拟涨跌；无收益诱导 |
| 13–17 | 渐进提供完整复盘但仍遵守低刺激、透明和隐私默认 | 共同制定边界并逐步放权 | 完整家庭模拟账本；仍非真实金融服务 |

0–2 岁可由家长留存家庭成长记录，但没有儿童自主操作路径，也不作为儿童端活跃用户。

## 3. 行为设计不变量

1. **单一焦点**：首屏只突出一个“现在做什么”，次要信息延后展示；一级导航最多 3 项。
2. **具体支架**：用“读一页、收好积木、告诉家长”代替抽象评分；步骤最多 3 个，结构固定为“看看 → 去做 → 给家长看”。
3. **稳定反馈**：奖励由家长预先定义、与明确行动对应；不用随机倍率、惊喜掉落、连胜、稀缺倒计时或故意延迟。
4. **过程反馈**：说“你完成了这一步”“可以请家长看看”，不说“你真聪明”“失败了”“今天断签了”。
5. **有限自主**：需要选择时最多同时给两个意义清楚、同等可见的选项；取消、暂停和家长协助不隐藏。
6. **现实迁移**：任务卡鼓励离屏行动；完成后交给家长形成回应闭环，不以继续浏览作为奖励。
7. **健康退出**：到限时后保存状态并温和结束；不展示刺激性倒计时，不用恐吓或羞辱文案。
8. **高隐私默认**：不诱导上传、分享、开定位或关闭保护；儿童不能自行修改隐私、费率、交易或限时配置。

## 4. 两遍设计方案

### 第一遍：令牌与结构

低唤醒视觉令牌控制在 6 色：云纸 `#F7F8F3`、森林墨 `#24332D`、苔绿 `#3D6B57`、雾绿 `#DDE7DF`、暖阳 `#E7B84B`、边界珊瑚 `#C96B5A`。儿童端主色使用苔绿，暖阳只标记一处下一行动，不用多块高饱和竞争注意力。

中文字体以系统 Sans 为主，保证字形和无障碍缩放；儿童行动标题 28–34sp、按钮 20–22sp、说明不低于 17sp。数字等宽字体只留在家长账本，不出现在 3–5 岁主路径。

```text
┌───────────────────────────────────────────────┐
│ 今天好。                         [请家长帮忙] │
│                                               │
│       看 看  →  去 做  →  给 家 长 看         │
│ ┌───────────────────────────────────────────┐ │
│ │  现在做：收好 5 块积木                    │ │
│ │                                           │ │
│ │              [ 我做好了 ]                │ │
│ └───────────────────────────────────────────┘ │
│                                               │
│       今天        小任务        我的          │
└───────────────────────────────────────────────┘
```

签名元素为“成长路标”：三个安静的叶片节点表达现在、行动、家长回应。它替代儿童端的三环统计仪表盘，不制造未完成压力；家长端可以继续使用数据型总览。

### 第二遍：自我评审与收敛

首稿若同时展示成长环、时间、XP、Coin、Money、流水和三项任务，会让量化指标抢走任务本身，也要求学龄前儿童理解抽象体系。最终方案删除儿童首页统计仪表盘，只保留一个下一任务、一个完成动作和固定路标；钱包/基金/费率退回家长端，“我的”只呈现星星、存起来和家庭奖励。视觉强调只使用在当前任务卡，其他区域保持安静。

## 5. 页面验收门禁

- CHILD 模式一级导航恰为 3 个；PARENT 模式可保留完整管理导航。
- CHILD 首页最多 1 个主按钮，最多显示 1 个待做任务；无成长环、流水、基金市值和三币并列指标。
- CHILD 任务卡不同时展示 Money/Coin/XP；3–5 岁文案不出现 NAV、费率、盈亏、手续费、流水和投资操作。
- CHILD 成长页不提供基金买卖、NAV 调整、零钱回收、兑换费率或调账；需要这些操作时明确“请家长一起”。
- 无连续签到、排行榜、抽奖、随机奖励、无限滚动、自动播放、强制分享或损失文案。
- 限时页提供温和结束和家长入口；动画尊重 Reduced Motion，核心理解不依赖颜色、动画或声音。
- 平板横屏与窄屏均可完成“查看一个任务 → 提交 → 等待家长”路径；真实触控和 TalkBack 需在设备可用后验收。
