# 06 Android UI 设计

## 导航结构

单 APK 启动后进入家庭选择/登录。CHILD 默认进入孩子壳；进入 PARENT 壳需 PIN。角色切换清空前一角色的敏感导航栈与缓存详情。

### 家长端

- 首页：孩子信息、今日学习/任务完成度、今日 App 使用时长、剩余时长、待审核、当前计划、本周成长、Money/Coin、待处理兑换/提现。
- 成长：计划、目标、任务、审核、里程碑。
- 家庭经济实验室：兑换比例、预算、储蓄奖励、虚拟基金/费用/NAV、Reward Shop。
- 报告：GrowthReport、FinancialReport。
- 设置：家庭成员、PIN、防沉迷时段/时长/休息规则、安全、数据导出/删除、服务连接。

### 孩子端

- 首页：头像、等级、XP、Coin、Money、今日学习/成长任务、今日剩余使用时长、连续天数、愿望。
- 任务：待办、详情、证据提交、审核结果。
- 财富：零钱、压岁钱、Coin、储蓄、愿望、模拟投资、零钱回收。
- 奖励：Reward Shop、订单状态。
- 成长：能力、里程碑与适龄报告。

## 核心交互约束

- 金融确认使用两步流程：预览 → 明细确认；明确本金、费率、手续费、净投入/到账、风险提示。
- 加载、空态、错误、离线、认证过期和权限不足都有独立状态；写操作不做乐观伪成功。
- 低龄模式使用大触控区、图标+文字和语音/家长协助入口；不得用连续签到羞辱、损失厌恶或赌博式动效诱导。
- Material 3、动态字体、深色模式、TalkBack、色彩对比与 Reduced Motion 纳入 UI 门禁。
- 平板横屏采用 12 列响应式网格：家长端可同时展示导航、孩子概览和待办；孩子端保持焦点单一、减少刺激。竖屏与手机折叠为单栏。
- 达到防沉迷限制时显示剩余/恢复时间和“请求家长解锁”，不使用恐吓或羞辱文案；PIN 输入不可从孩子导航栈绕过。

## 页面状态与缓存

ViewModel 使用不可变 `UiState`。Room 可缓存任务列表、只读余额快照和未上传证据草稿；所有金融确认需在线读取最新预览，离线不得执行账本写入。图片上传采用受控大小、类型检查、断点/重试与上传后引用，不把原始路径写日志。
