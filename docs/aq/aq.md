# 待澄清问题（AQ）

以下问题不阻塞 Phase 0，但须在对应 Stage 实现前决定：

1. 家庭局域网部署的目标宿主是 Windows、macOS、NAS 还是 Android 同机？当前设计按独立 Spring Boot 宿主处理。
2. V1 正式数据库是否接受 PostgreSQL？需求允许 H2/SQLite 类本地库或 MySQL；为账本事务、并发与迁移一致性，当前建议 PostgreSQL，H2 仅测试。
3. 孩子是否拥有独立口令，还是由家长设备内切换？当前设计支持账号登录，并把“同设备受控切换”作为 V1 简化路径。
4. Money 精度是否固定人民币分（2 位小数），Coin 是否只允许整数？当前设计如此约束。
5. 儿童图片的保留期、导出格式与删除后的审计保留期限需产品/隐私评审确认。
6. 目标平板的 Android 版本、屏幕尺寸/分辨率与是否长期横屏固定，决定 Stage 2 的最低 SDK 和 UI 验收设备矩阵。
7. Stage 15 已为新安装采用每日 20 分钟、单次 10 分钟的 3–5 岁保守 App 内默认，家长可调整且升级不覆盖已有值；休息时间和允许时段的生产策略仍需家长产品评审。
8. “中间商赚取提现手续费”当前解释为家长设置的家庭教育规则，手续费留在家庭账本内且完全透明；若意指平台收取真实费用，将超出 V1 金融边界，不能直接实现。
9. 国家中小学智慧教育平台能否把视频流直接内置？用户说明 App 仅家庭自用、不发布，但平台《网站声明》仍明确未经许可 App 不得转载或改编。Stage 21 当前采用受限 WebView 直接浏览官方 HTTPS 页面，不复制、抽取、缓存或转码视频；直接视频流、离线包和页面改编在取得平台许可或官方 SDK/API 前不实现。
10. 家长填写任意教育网站后，是否都能自动读取栏目？不能保证。Stage 21 只解析公共 HTTPS 静态 HTML 的导航链接，动态 JavaScript、登录、反爬、跨域导航和非 HTML 来源会安全失败并保留旧快照；不为提高成功率绕过站点控制。若需要稳定深度接入，后续应为明确来源增加经审核的官方 API/适配器。
