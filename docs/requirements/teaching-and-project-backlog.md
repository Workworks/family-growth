# 全面教学能力与项目剩余事项清单

文档性质：`BASELINE_AUDIT`

日期：2026-08-26

来源：REQ-001–031、初始 80 节需求、当前代码、Stage 报告、TODO、BLOCKERS、AQ 与已知限制。

本文是范围审计和待办分解，不替代 Stage 报告。正式实现仍须先建立对应 Stage Spec；完成状态必须以代码、目标数据库、Android 自动化、真机和平板证据为准。

## 1. 当前教学能力事实

当前已具备基础任务闭环，以及 Stage 21 V11 交付的一条生产教学纵切：

- 服务端有基础 `GrowthPlan → GrowthGoal → GrowthTask`、孩子提交、家长审核和 XP/Coin/Money 奖励。
- Android 本机任务是扁平的标题、分钟数、奖励和 `TODO/SUBMITTED/APPROVED` 三状态。
- “安静小课堂”只有 3 个写死在 APK 内的 18 秒原创视频；累计播放 90% 后提交固定奖励任务。
- V11 已有不可变 Course/Version/Unit/Lesson、九类 Activity、服务端题目判定、Assignment/Attempt/Completion/MasteryEvidence、复做和生产 API；Android 已接学习路径、安装包视频实际播放计时、活动提交和家长审核。
- Stage 21 V12 已补齐 Android 加密学习 outbox、进程重建后的待登录恢复、401 保留、409 显式合并和家长“一课一活动”建课/发布/分配；目标平板密钥库/杀进程回放、完整多课节编辑、足量课程内容和完整能力图谱仍未实现。

因此，当前工程代码已能验证“可视化建课—发布—分配—多活动—加密待同步—提交—复做/确认”的生产事实链，但在目标平板回放前仍不能宣称离线可靠；也不能宣称支撑全面课程、长期排课、足量内容、完整报告和四学段深度运营。

截至 2026-08-28：T-02、T-05–T-09 的共用引擎纵切已由 V11 交付；T-02 的年龄/难度/先修深化、T-03/T-04、T-10 的离线可靠性和 T-11 的完整权利/下架机制仍是后续范围。下表继续保留完整完成定义，不能因基础纵切而整体划为完成。

## 5. 明确不是待办的边界

- 不接真实银行、微信/支付宝自动支付、证券、真实基金或行情。
- 不做面向儿童的排行榜、连续签到、抽奖宝箱、随机奖励、无限滚动、自动播放或损失施压。
- 不把本 App 防沉迷宣称为系统级跨 App 家长控制。
- iOS、多租户 SaaS、公开社交和开放内容推荐流不是当前范围。

## 6. 重新编排后的建议实施顺序

以下只是建议拆分，尚未建立 Stage 状态事实：

1. **建议 Stage 20（P0）— 学段底座与家长配置**：T-01、T-23–T-25、T-30 的基础部分；完成服务端年龄/推荐/覆盖/审计、Android 路由、反馈档案和纪录片来源模型。先解决“显示哪套页面”，再扩展内容。
2. **建议 Stage 21（P0）— 共用课程与证据引擎**：T-02–T-11；建设 Course/Unit/Lesson/Activity、题库、Attempt、MasteryEvidence、Completion、内容版权状态和生产 API。
3. **建议 Stage 22（P0）— 幼儿园故事舞台**：T-12、T-14/T-15 首批、T-17；交付 3–4/5–6 岁内容带、明显且安全的反馈、亲子活动和首批经权利审查纪录片目录。
4. **建议 Stage 23（P1）— 小学探索手册**：T-26；交付低/高年级、主要学科、练习/阅读/实验、错题再练和小学报告。
