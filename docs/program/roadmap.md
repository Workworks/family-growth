# 产品路线图

- V1：Android 平板双模式、学习/成长任务、App 内防沉迷、今日使用统计、三类奖励、钱包账本、压岁钱、兑换、奖励商店、储蓄、愿望、模拟基金、带透明手续费的零钱回收与基础报告。
- V1 当前最高准则：儿童端从 3 岁起，3–5 岁亲子共用、一次一个行动、最多三个一级入口；复杂财商由家长托底，禁止操纵性参与机制。
- 教学主线 Stage 20–26 已完成可离线范围并因目标平板/服务保持运行态阻塞。REQ-051 完成性审计后的当前主线是 Stage 27 成长档案 → Stage 28 奖励治理 → Stage 29 家庭协作 → Stage 30 可靠同步 → Stage 31 虚拟经济深化 → Stage 32 工具链与最终治理。
- 后续深化：离线体验、更多成长内容与家庭虚拟经济消耗项；任何深化仍服从儿童最佳利益门禁。
- 长期禁区：真实证券/基金代销、真实银行和自动支付、真钱赌博、面向儿童的诱导交易或不透明费用。
