# 已知限制

**最后更新：2026-08-31。**

| ID | 限制 | 影响 | 解除条件 |
| --- | --- | --- | --- |
| LIM-001 | Stage 3 已有认证/PIN，但尚无多家长邀请、PIN 恢复与可信 TLS 配对 | 不能直接暴露到互联网；局域网生产部署仍需运维配置 | Stage 8–10 补部署/配对/恢复验收 |
| LIM-002 | Android Emulator 无法建立可用 ADB | 无安装、启动、旋转证据 | 使用真机/平板或经授权重装共享 system image |
| LIM-003 | 历史 debug APK 与当前 release 证书不同 | 已装 debug 包不能直接覆盖为稳定包 | 卸载 debug 包后安装 0.2.0 release 基线；后续只使用同一 release 证书 |
| LIM-004 | v0.2.0–v0.3.9 稳定 Release 使用同一证书；v0.3.3→v0.3.4 已由用户确认可更新，但 v0.3.8→v0.3.9 尚未真机覆盖升级 | v0.3.9 远端契约、digest、包名、版本和签名通过，Room/Keystore、最新业务和加密待办的数据保留仍无设备证据 | 真机保留现有数据从 v0.3.8 应用内更新至 v0.3.9，回放数据、加密 outbox 和失败路径 |
| LIM-005 | Stage 3–7/9 生产服务端已完成，Stage 8 真机和 Stage 10 总验收未完成 | API/账本/报告可自动化验证，但尚无目标平板多端联调证据 | 完成 Stage 10 离线交付并连接目标平板回放 Stage 8/10 |
| LIM-006 | `RESOLVED`：Stage 32 升级至 AGP 8.13.2 / Gradle 8.13 / JDK 17，官方支持 API 36.1 | 全量 Android 门禁不再出现旧兼容警告 | 版本固定并由 Wrapper SHA-256 校验；后续升级继续先查官方兼容表 |
| LIM-007 | 防沉迷仅设计 App 内控制 | 不提供系统级跨 App 管控 | V1 保持产品边界并准确提示 |
| LIM-008 | 钱包、提现和基金均为家庭内部模拟 | 不支持真实支付/投资 | 属产品安全边界，不计划解除 |
| LIM-009 | 0.2.2 业务状态保存在 App 私有 SharedPreferences | 没有跨设备同步、服务端备份或业务数据加密层 | 后续服务端同步与本地敏感数据加密设计 |
| LIM-010 | Stage 15 儿童端缺少真实平板、TalkBack、字体放大与 Reduced Motion 回放 | 自动化能证明结构契约，不能证明 3 岁儿童实际可用性 | 连接目标平板并由家长陪同执行可用性验收 |
| LIM-011 | Android 待上传 UsageEvent 仅保存在当前进程内 | 短时断网重试幂等，但进程被系统终止时尚未上传的分钟事件可能丢失 | 后续隐私评审后采用加密的最小本地 outbox，并配置保留/删除期限 |
| LIM-012 | `RESOLVED`：Stage 17 已交付服务端冻结式零钱回收、PAID 扣账和透明费用快照 | 服务端生产闭环已具备；Android 复杂家长界面仍不在本 Stage | V8、H2/PostgreSQL 16.15、权限/幂等/并发证据见 Stage 17 |
| LIM-013 | `RESOLVED_OFFLINE`：Stage 26 已实现家长导出、两阶段受约束删除、自动保留、睡眠窗、服务端会话/强制休息与临时放行审计 | H2/PostgreSQL 和 Android 双变体已证明工程边界；目标平板/HTTPS 运行态以及外部备份到期销毁仍不能由主库测试替代 | 代码证据见 Stage 26；设备项按 V26-08 回放，备份按运维轮换验证 |
| LIM-014 | `PARTIALLY_RESOLVED`：Stage 21 V12 已实现 Keystore AES/GCM 加密 outbox、401 保留、409 显式合并和家长一课一活动建课；尚无目标平板密钥库、杀进程/断网和无障碍 E2E | 自动化证明模型和构建，不足以宣称设备上的离线零丢失；完整多课节编辑和足量课程也未交付 | 在目标平板连接测试服务，回放写前落盘、强制结束进程、重新登录、401/409、队列清空与 TalkBack/旋转 |

外部阻塞的责任方和下一动作见 [BLOCKERS](../BLOCKERS.md)。
