# 已知限制

**最后更新：2026-08-25。**

| ID | 限制 | 影响 | 解除条件 |
| --- | --- | --- | --- |
| LIM-001 | 基础 API 尚无生产认证/PIN | 不可对家庭网络开放为正式产品 | 后续认证 Stage 完成并有权限反向测试 |
| LIM-002 | Android Emulator 无法建立可用 ADB | 无安装、启动、旋转证据 | 使用真机/平板或经授权重装共享 system image |
| LIM-003 | 历史 debug APK 与当前 release 证书不同 | 已装 debug 包不能直接覆盖为稳定包 | 卸载 debug 包后安装 0.2.0 release 基线；后续只使用同一 release 证书 |
| LIM-004 | 0.2.0/0.2.1 稳定 Release 已发布但尚未真机覆盖升级 | 远端契约、digest 与签名通过，运行态仍无证据 | 真机安装 0.2.0，通过 App 更新至 0.2.1并检查数据保留 |
| LIM-005 | Stage 3–10 生产服务端深度闭环未建设 | 0.2.1 仅能作为单设备本机基础体验，不能多端协作或生产部署 | 按 Stage 顺序实现服务端领域、认证、同步并验收 |
| LIM-006 | AGP 8.7.3 仅声明测试到 compileSdk 35，工程使用 36 | 构建有兼容警告 | 后续升级 AGP 或对齐 SDK/依赖基线 |
| LIM-007 | 防沉迷仅设计 App 内控制 | 不提供系统级跨 App 管控 | V1 保持产品边界并准确提示 |
| LIM-008 | 钱包、提现和基金均为家庭内部模拟 | 不支持真实支付/投资 | 属产品安全边界，不计划解除 |
| LIM-009 | 0.2.1 业务状态保存在 App 私有 SharedPreferences | 没有跨设备同步、服务端备份或业务数据加密层 | 后续服务端同步与本地敏感数据加密设计 |

外部阻塞的责任方和下一动作见 [BLOCKERS](../BLOCKERS.md)。
