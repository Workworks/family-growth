# 已知限制

**最后更新：2026-08-26。**

| ID | 限制 | 影响 | 解除条件 |
| --- | --- | --- | --- |
| LIM-001 | Stage 3 已有认证/PIN，但尚无多家长邀请、PIN 恢复与可信 TLS 配对 | 不能直接暴露到互联网；局域网生产部署仍需运维配置 | Stage 8–10 补部署/配对/恢复验收 |
| LIM-002 | Android Emulator 无法建立可用 ADB | 无安装、启动、旋转证据 | 使用真机/平板或经授权重装共享 system image |
| LIM-003 | 历史 debug APK 与当前 release 证书不同 | 已装 debug 包不能直接覆盖为稳定包 | 卸载 debug 包后安装 0.2.0 release 基线；后续只使用同一 release 证书 |
| LIM-004 | 0.2.0/0.2.1/0.2.2 稳定 Release 已发布但尚未真机覆盖升级 | 远端契约、digest 与签名通过，运行态仍无证据 | 真机安装 0.2.1，通过 App 更新至 0.2.2 并检查数据保留 |
| LIM-005 | Stage 3–7/9 生产服务端已完成，Stage 8 真机和 Stage 10 总验收未完成 | API/账本/报告可自动化验证，但尚无目标平板多端联调证据 | 完成 Stage 10 离线交付并连接目标平板回放 Stage 8/10 |
| LIM-006 | AGP 8.7.3 仅声明测试到 compileSdk 35，工程使用 36 | 构建有兼容警告 | 后续升级 AGP 或对齐 SDK/依赖基线 |
| LIM-007 | 防沉迷仅设计 App 内控制 | 不提供系统级跨 App 管控 | V1 保持产品边界并准确提示 |
| LIM-008 | 钱包、提现和基金均为家庭内部模拟 | 不支持真实支付/投资 | 属产品安全边界，不计划解除 |
| LIM-009 | 0.2.2 业务状态保存在 App 私有 SharedPreferences | 没有跨设备同步、服务端备份或业务数据加密层 | 后续服务端同步与本地敏感数据加密设计 |
| LIM-010 | Stage 15 儿童端缺少真实平板、TalkBack、字体放大与 Reduced Motion 回放 | 自动化能证明结构契约，不能证明 3 岁儿童实际可用性 | 连接目标平板并由家长陪同执行可用性验收 |
| LIM-011 | Android 待上传 UsageEvent 仅保存在当前进程内 | 短时断网重试幂等，但进程被系统终止时尚未上传的分钟事件可能丢失 | 后续隐私评审后采用加密的最小本地 outbox，并配置保留/删除期限 |

外部阻塞的责任方和下一动作见 [BLOCKERS](../BLOCKERS.md)。
